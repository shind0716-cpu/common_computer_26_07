## 사람용 세 줄

1. **이 문서가 뭔지** — 미니테스트 1~5호(토론 실험 정찰)를 마친 상태에서, 무엇이 어디에 있고 어떻게 돌리며 무엇을 사람이 정해야 하는지 안내하는 인계 지도입니다.
2. **처음 할 일** — 쉬운 보고서 한 편을 읽고(§2), 아래 드라이런(실제 호출 없이 화면 조립만 하는 0콜 실행) 세 줄을 돌려 환경을 확인하세요(§4).
3. **결정 대기 목록** — 이 문서 §7에 있습니다. 전부 사람(팀·멘토)이 정할 몫이고, 정하기 전에는 본실험을 실행하지 않습니다.

## §2. 프로젝트가 재는 것

AI 여러 개가 대화로 협업할 때, 처음에 준 사실이 중간에 사라지는 조건을 찾는 실험입니다. 배경·질문·수확은 쉬운 보고서의 머리("사람용 세 줄"과 "이 정찰의 수확" 표)에 있습니다 — `experiments/debate_role_minitest/미니테스트-쉬운보고서-2026-08-20.md`. 여기서 다시 요약하지 않습니다.

## §4. 실행 방법 (아래 명령 전부 드라이런으로 실행 확인함 — 실 API 0콜)

**환경**: 리포 루트에서 실행. `PYTHONUTF8=1` 필수(Windows 인코딩). API 키는 리포 루트 `.env` — `OPENAI_API_KEY` · `GEMINI_API_KEY` (GLM은 `GLM_API_KEY`+`GLM_BASE_URL`, Anthropic 키는 현재 팀에 없음). 키가 없으면 러너가 시작 전에 멈춥니다(`modules/llm.py` 의 `preflight`).

```bash
# 토론 러너 — 계획 단위 실행. --dry = 0콜 조립 리허설(runs/_dry/에 저장), 빼면 실호출
PYTHONUTF8=1 python experiments/debate_role_minitest/run_minitest.py --mt5 --dry
#   계획 스위치: (없음)=1호 6판 42콜 · --mt2 6판 42콜 · --mt3 8판 84콜 · --mt4 8판 88콜 · --mt5 8판 56콜
#   이미 결과가 있는 판은 [skip] — 기존 런을 절대 덮어쓰지 않는다

# 앵커 스캐너 — 집계(LLM 0콜). 신규 런만 스캔해 기존 행 무수정으로 덧붙인다
PYTHONUTF8=1 python experiments/debate_role_minitest/scan_minitest.py

# 단독(1인) 러너 — 토론이 아닌 혼자 고쳐 쓰기 실험(PREREG v1 계열)
PYTHONUTF8=1 python experiments/memory_structure/run_solo.py --dry
#   주요 인자: --model gpt|gemini · --max-calls N(초과 즉사) · --issue(재료)·--stance-key
```

**콜 예산 관행**: 모든 러너는 호출 상한 상수를 갖고 초과 시 즉시 중단하며, 호출 단위 체크포인트(`.partial.jsonl`)로 중단 지점부터 재개합니다. 실호출 전에 반드시 워크오더에 콜 수를 적고 승인받습니다(관행의 실물은 §3 워크오더 5건).

## §5. 일하는 방식 (이 폴더의 규율 6줄)

1. 실행 전 작업 지시문(워크오더)을 쓰고 **사람 승인**을 받는다 — 승인 표기가 없으면 실행 금지.
2. 탐색 실행의 리포트 머리에는 "탐색 · 사전등록 없음 · 수치 인용 금지"를 박는다.
3. 기존 런·표는 수정하지 않고 **덧붙인다**(append) — 정정도 새 글로.
4. 원자료(프롬프트·응답 전문)는 전량 보존한다 — 요약 저장은 이 프로젝트가 연구하는 바로 그 실패다.
5. 주장(증거로 쓰는 수치)은 사전등록을 거친 본실험에서만 만든다.
6. 노션 게시는 사람이 결정한다 — 클로드는 초안까지만.

## §8. 하지 말 것

- 미니테스트(1~5호)의 수치를 **어떤 주장의 증거로도 인용하지 않는다** — 조건당 1~2회 정찰이다.
- 기존 리포트·런·표를 수정하지 않는다 — 정정은 새 문서로 덧붙인다.
- 사전등록 없이 본실험을 실행하지 않는다 — §7의 결정들이 먼저다.
