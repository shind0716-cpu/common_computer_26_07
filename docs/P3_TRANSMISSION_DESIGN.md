## 0. 한 줄 요약

전달(transmission)을 **한 겹으로 재면 앵커 논문의 최대 비약 FOL-8("말함을 재고 앎을
결론")을 그대로 반복한다**. 그래서 2층으로 잰다 — 층 1(전달-발화: 로그 전수, 추가 LLM 호출 0)이
주지표를 내고, 층 2(전달-보유: 회고 프로브 표본 조사)가 층 1의 오분류 보정 계수(α, β)를
공급한다. 두 층은 보정식 **TR̂ = TSR·(1−α) + (1−TSR)·β** 로 연결된다.

레이더의 원점은 **노출(exposure)** 이다. 이 아키텍처는 누적 대화록이 없고 직전 라운드
발화만 보이는 롤링 창(§2-0)이므로, "표상적으로 떠오른" 팩트란 정확히 "지금 창에 있는"
팩트이고, 전달 사건은 **노출이 선행된 언급**만으로 센다(§3-2). 노출 없는 언급은 전달이
아니라 사전지식/작화 신호(prior_suspect)다.

## 1. 목적과 위치

- 민옥 7/24 "소실 4관문": 보유(회고 프로브) → 발화(FAR·팩트시계) → **전달(계기 공백 ←
  이 설계의 대상)** → 사용(결정 과제).
- 동범 7/24 재정의안: 앵커 논문(DelibTrace, arXiv:2606.03032)의 최대 비약 FOL-8 =
  "말함(saying)을 재고 앎(knowing)을 결론". 전달 관문의 정의는 **"원래 모르던 에이전트가
  획득했는가"** — 발화 지표만으로는 이 정의에 닿지 못한다.
- 본 문서는 요한이 7/27 보드(입장 정리)에서 담당 확정한 **전달 관문의 도달 프로브 설계
  초안**이다. 기존 계기(FAR·조건부 hazard·fact-clock)는 전부 **화자 무관 시스템 수준**
  이거나 발화 수준이라, "누가 누구에게 도달했는가"는 현행 파이프라인의 계기 공백이다.

## 2. 2층 구조 (확정 골격)

**핵심 통찰**: 전달을 한 겹(발화만 / 보유만)으로 재면 FOL-8을 반복한다. 발화만 재면
에코(따라 말했으나 남지 않음)를 전달로 오인하고, 보유만 재면 침묵 획득(들어서 알지만
말하지 않음)의 발화 경로를 놓친다. → **2층 고정**(D1).

- **층 1 — 전달-발화 (주지표)**: 로그 전수 조사, **추가 LLM 호출 0**, 읽기 전용.
  (입력인 `agents_mentioning` 자체는 LLM judge 산출물이다 — "호출 0"이 아니라 "추가 호출
  0"이며, 그래서 귀속 신뢰도 조항(§4)이 층 1의 전제 조건이다.)
  비보유자 언급 = assignment `agents[].assigned_fact_ids` × judgment
  `stages[].facts[].agents_mentioning` 교차.
- **층 2 — 전달-보유 (검증층)**: 회고 프로브(recall)의 **비보유자 확장** — 표본 조사.
  층 1 판정을 대체하지 않고, 층 1의 오분류율(α, β)을 추정해 보정 계수를 공급한다.

### 2-0. 관측된 정보 생태 — 설계의 물리적 전제 (modules/debate_engine.py 코드 확인 완료)

앵커 논문 계승 엔진의 프롬프트 조립을 직접 확인한 사실 3건:

1. **round 0(initial)**: 에이전트 입력 = question + **자기 할당 팩트 전문** + 입장.
   할당 팩트는 **이후 라운드에 재공급되지 않는다**(`initial_utterance`만 facts 슬롯 보유).
2. **round r≥1(continue)**: 입력 = question + **자기 직전 발화 1개** + **이웃(edges)의 직전
   발화** + setting (+ ledger v0의 inject 블록은 **전원에게**). **누적 대화록 없음 — 가시
   창은 정확히 한 라운드**(`previous` 배열만 전달).
3. **토폴로지** `build_edges` = full(자기 제외 전원) / tree / line. 현행 config
   (sprint_mini·mini_h2 쌍)는 structure 미지정 → **full 기본**. 좌석 배치는 debate.jsonl의
   `seating` 이벤트(seed 셔플)에 기록된다.

세 귀결이 본 설계의 골격을 정한다:

- (i) **노출이 로그에서 전수 관측 가능** — X(a,f,r)을 추가 LLM 호출 0으로 정의할 수 있다(§3-2).
- (ii) **인과 순서가 구조적으로 깨끗** — round r의 발화는 r−1 창만 볼 수 있으므로 같은
  라운드 안에서의 전달이 물리적으로 불가능하다. 라운드 해상도가 곧 인과 해상도다.
- (iii) **보유의 유일한 자기 채널 = 자기 발화 사슬** — f를 한 라운드 빼먹으면 자기 채널에서
  소멸하고, 재노출(이웃/장부) 없이는 복귀 불가. 따라서 전달 = **운반 사슬(carrier chain)의
  복제**이고, H-T1("전달 폭 = 복구 경로")은 은유가 아니라 이 생태의 기계적 귀결 후보다.

### 2-1. (비보유자 a, 팩트 f) 2×2 분할표

층 1 사건 S(a,f) = "a가 f를 언급했다"(§3-2), 층 2 사건 R(a,f) = "a가 f를 회고했다"(§3-6).

| | R=1 (회고 성공) | R=0 (회고 실패) |
|---|---|---|
| **S=1 (언급)** | **확증 전달** | **에코** — 말했으나 남지 않음 (층 1 거짓양성) |
| **S=0 (비언급)** | **침묵 획득** — 층 1 사각 | **미전달** |

### 2-2. 보정식 (지표 연결의 핵심)

- α = P(회고 실패 | 언급, 비보유) — 에코율(층 1 거짓양성률)
- β = P(회고 성공 | 비언급, 비보유) — 침묵 획득률(층 1 사각률)

> **TR̂ = TSR·(1−α) + (1−TSR)·β**

유도: TR = P(획득) = P(S=1)·P(R=1|S=1) + P(S=0)·P(R=1|S=0). 층 2가 층 1의 보정 계수를
공급하는 **오분류 보정(misclassification correction)** 구조다. α·β는 표본 추정치이므로
TR̂는 **구간으로 보고**하며, 구간이 판별 기준을 걸치면 **무승부**를 선언한다(§7-5).
α·β의 추정은 **out-of-window 프로브에서, prior 밴드 내에서**(최소 low-prior 정본) 한다 —
규칙은 §3-6. 밴드 혼합 추정은 TR̂를 편향시킨다. **결합은 동일 목표 모집단끼리만**:
TR̂_low = TSR_low·(1−α_low) + (1−TSR_low)·β_low 처럼 같은 층의 양들만 조합한다.
α·β의 주추정 표본은 **확률표본(층화 무작위)** 이어야 하며, 능동 표본추출분을 단순 비율에
합산하는 것을 금지한다(§7-5의 표본 설계 원칙).

한정: R은 "회고 가능한 보유"의 근사다(회고 실패 ≠ 보유 부재의 증명). 따라서 TR̂의 조작적
의미는 "**회고 프로브로 확인 가능한 전달**"로 한정하고, 이 한계를 보고서에 의무 명기한다.

## 3. 지표 정의 (형식화)

### 3-0. 표기

- A = assignment의 에이전트 집합, F = facts의 팩트 집합.
- **보유자** H(f) = {a ∈ A : f ∈ a.assigned_fact_ids} (assignment 기준 사전 보유).
- **비보유자** N(f) = A ∖ H(f).
- "원래 모르던"의 정본 근사 = **비할당 ∧ low-prior** (비할당이어도 high-prior 팩트는
  사전지식으로 알 수 있다 — D2·§5-3). 전 밴드 집계는 병기.
- M(a, f, t) ∈ {0,1}: judgment stage t의 팩트 f 레코드에서 a ∈ `agents_mentioning`.
- 적용 범위: **실험 트랙(stage_type="round")만**. 관찰 트랙(summary_layer)은 동결 중이고,
  요약 레이어의 agents_mentioning은 발화 시점 의미가 다르다(P2 질문 B와 동형의 이유).

### 3-1. 입력 계약 (P2_INPUT_CONTRACT 방식 — 층 1이 읽는 필드 전부)

| 파일 | 경로 | 용도 | 성격 |
|---|---|---|---|
| assignment | `agents[].agent_id`, `agents[].assigned_fact_ids` | H(f)/N(f) 분할 | hard(없으면 계산 불성립) |
| judgment | `stages[].stage` | 시간축 정렬(정렬 가능 정수 — 구조 확정 §2) | hard |
| judgment | `stages[].facts[].fact_id`, `status` | 도입 시점 t₀ (fact-clock과 동일 정의) | hard/soft(P2와 동일) |

### 3-2. 층 1 사건과 기본 지표 — 노출 선행 조건

- **노출** X(a,f,r) ∈ {0,1}: a의 round r 입력 창에 f가 있음 =
  [∃ j ∈ edges(a) : M(j,f,r−1)=1] ∨ [round r의 `ledger_inject`에 f 포함].
  **첫 노출** e(a,f) = min{r : X(a,f,r)=1} (없으면 ∞ — 음영 지대).
- **상수 노출 채널 — question (레이더 영점 조정)**: question(issue의 `question` 필드,
  없으면 `title` — debate_engine 확인)은 **매 라운드 전원의 프롬프트에 있는 상시 노출**이라
  X로 모델링되지 않는다. question 텍스트에서 판독 가능한 팩트는 전달을 추적할 수 없으므로,
  run 전에 question 텍스트를 judge_fact로 **1회 스캔**해 매칭되는 팩트를 `question_exposed`
  로 라벨하고 **추적자 정본에서 제외**한다(제외 목록은 산출물에 병기). 이슈 등록 시
  `question` 필드를 팩트 누출이 최소인 질문 문장으로 두기를 권장한다(예: 둘째 이슈 후보 1의
  제목은 팩트 #2 요지를 누출하므로 question 필드 별도 지정 필요).
- **전달-발화 사건**: a ∈ N(f), 첫 언급 τ(a,f) = min{t : M(a,f,t)=1} 이고
  **e(a,f) ≤ τ(a,f)** (노출 선행). 노출 이전 언급(τ < e)은 전달이 아니라
  **prior_suspect**(사전지식/작화)로 분리 집계한다 — round 0의 비보유 언급은 입력에 자기
  할당 팩트뿐이므로 **정의상 전부 prior_suspect**다(§2-0-1).
- **엄격/상한 이중 계상 (7/27 검토 확정)**: 노출 당회 첫 언급(u=0 — f가 처음 창에 들어온
  바로 그 라운드의 언급)은 창의 내용을 그대로 읽어 옮기는 **창 안 반향(읽기)** 일 수 있다.
  따라서 **주지표(엄격)는 u ≥ 1 획득만 계상**하고, u=0 첫 언급은 `u0_immediate` 플래그로
  분리 집계하며, u=0 포함 집계는 **상한 민감도 분석**으로 병기한다. 롤링 창 특성상 u≥1 첫
  언급은 대부분 재노출(X(a,f,τ)=1)을 경유하므로, τ 시점의 재노출 여부(창 안/창 밖)를 함께
  보고한다 — **창 밖(X=0) 첫 언급**은 창 없이 운반된 표상의 가장 강한 발화 증거다.
- **전달 폭** B(f) = |{a ∈ N(f) : 노출 선행 첫 언급 존재, u ≥ 1}| (엄격 정본).
  B_upper(f) = u=0 포함 상한. 이하 B는 엄격 정본을 가리킨다.
- **TSR(f)** (Transmission-Saying Rate) = B(f) / |N_exp(f)|,
  **N_exp(f) = {a ∈ N(f) : e(a,f) < ∞}** — 분모는 **노출된 비보유자만**. 비노출 쌍(e=∞)은
  전달 실패가 아니라 무기회이므로 분모에서 빼고 `n_never_exposed`로 별도 보고한다
  (fact-clock의 `n_never_introduced` 관례와 동형). full 토폴로지에선 f가 한 번 발화되면
  대개 전원이 노출되지만, 조기 소멸 팩트와 tree/line 일반화에서 갈린다. |N_exp|=0 → None.
- 시스템 수준 병기: TSR_system = 노출 쌍 풀링 비율, TSR_critical = critical 한정.

### 3-3. 획득 hazard h_acq(u) — fact-clock 검열 형식화의 획득 방향·쌍 수준 이식 (D4)

FACTCLOCK_PREREG §2의 좌표계·검열 규칙을 사건 방향을 뒤집고 쌍 수준으로 내려 이식한다.

- 단위 = (a, f) 쌍, a ∈ N(f), **e(a,f) < ∞인 쌍만**(비노출 쌍은 모집단 제외·별도 카운트 —
  §3-2).
- **t₀ = e(a,f) — 쌍별 첫 노출 정렬.** (v0.1의 "팩트 도입 정렬"을 개정: 도입은 시스템 수준
  사건이라 개별 비보유자의 수신 창과 어긋난다 — 늦게 노출된 에이전트의 무기회 구간이 분모에
  들어가 h_acq가 눌린다. 첫 노출 정렬이 FACTCLOCK 원칙 1 "관측창 안에서만 분모"의 쌍 수준
  이식이다.) age u = 첫 노출 후 u번째 round.
- **사건** = 노출 선행 첫 언급 τ(a,f) — "획득(acquisition)"의 발화 수준 사건.
  주지표는 엄격 규칙(u≥1, §3-2)을 따르고 u=0 포함은 상한 민감도로 병기한다.
- **우측 검열**: 관측 끝(마지막 round)까지 미언급이면 검열. at_risk(u) = "아직 미획득이고
  관측창 ≥ u인 쌍" — 늦게 노출된 쌍은 자기 관측창을 넘는 age의 분모에서 자동 제외된다
  (요한 설계 원칙 1의 형식화, fact-clock과 동일).
- h_acq(u) = acquisitions(u) / at_risk(u). at_risk=0이면 None. 누적 CIF(1−Π(1−h)) 병기.
- 노출은 지속 상태가 아니라 **라운드별 점멸**이다(롤링 창 — §2-0). 첫 노출 정렬 hazard는
  주지표로 두고, **시변 노출 지시자 X(a,f,t)와 누적 노출 용량 E(a,f,t)=Σ_{r≤t}X** 를
  회귀(§7-2)의 공변량으로 병기해 재노출 효과를 흡수한다.
- (v0.1 §3-3의 "동시 도입 언급 u=0 규칙"은 **폐기** — §2-0-(ii)에 의해 같은 라운드 내
  전달이 구조적으로 불가능해 동시성 문제 자체가 소멸했다. prior_suspect 판정은 §3-2의
  노출 선행 조건이 완전히 대체한다.)

### 3-4. 경로 분해 — T_organic vs T_ledger (D3)

H2의 기전 질문("장부 효과는 재발화인가 실전달인가")을 분해하기 위해, 획득을 **첫 노출의
채널**로 나눈다(v0.1의 "inject 선행 여부" 규칙을 대체 — 노출 정의가 생겼으므로 채널을
직접 읽는다).

- 첫 노출 라운드 e(a,f)의 원천: 이웃 발화(X의 첫째 항)면 **T_organic**, `ledger_inject`
  (둘째 항)면 **T_ledger**, 같은 라운드에 둘 다면 **T_mixed**(합치지 않고 분리 보고).
- stage↔round 정렬 전제: 구조 확정 §2(실험 트랙 0-기반 [0..N], round 0 포함)에 의해
  judgment stage와 debate round가 동일 좌표다.
- **해석 한정(명시)**: 채널 라벨은 "첫 노출이 그 경로로 왔다"는 관측 라벨이지 인과 주장이
  아니다(첫 노출 이후의 재노출 경유 획득은 시변 X·E 공변량(§3-3)이 회귀에서 흡수한다).
  on/off 쌍 비교에서 off의 T_organic 대비 on의 T_organic+T_ledger+T_mixed 증분을 함께
  봐야 기전 분해가 된다.

### 3-5. prior 층화 (D2)

- 밴드: **low** = prior.score ≤ θ_low / **high** = ≥ θ_high / mid = 그 사이 /
  unknown = null(별도, 밴드에 합치지 않음). **확정값 θ_low = 0.3, θ_high = 0.7**
  (7/27 검토 승인 — 확인 #1 해소). 이 경계는 자연적 경계가 아니라 **사전고정된 조작적
  층화**임을 보고서에 명시하고, 회귀(§7-2)에서는 prior.score **연속값을 병기**한다.
- **low-prior만 전달 추적자(tracer)의 정본**이다 — high-prior의 비보유자 언급은 획득이
  아니라 사전지식일 수 있어 층 1 신호가 오염된다. 주보고 = low-prior, 전 밴드 병기.
- prior=0을 보장하는 카나리아 팩트는 데이터 변경(리더 사안)이라 부록 §7-4로 분리.

### 3-6. 층 2 — 회고 프로브 확장 (표본 조사)

- 도구: recall(39447a4)의 **open 모드**를 비보유자에게 확장 — replay 재조립 + prompt_hash
  전수 검증 + 프리필 인터뷰 + **judge_fact 재사용**(잣대 단일화: recalled = status ∈
  judge.SURVIVING — recall.py의 기존 규칙 그대로).
- R(a,f) = 1 ⇔ a의 자유 회상문에서 f가 recalled.
- **창 밖 회고(out-of-window)가 층 2 정본**: replay 프리필의 컨텍스트에는 그 시점의 가시
  창(이웃 직전 발화 + inject 블록)이 포함되므로, 창에 f가 있는 시점의 회고 성공은 보유가
  아니라 **읽기**일 수 있다. 따라서 α·β 추정용 프로브는 **X(a,f,r)=0인 (a,r)** 에서 뽑고,
  in-window 프로브는 읽기 대조군으로 분리 보고한다. 프로브 시점 기본값은 최종 round 직후,
  시점 민감도는 층 2 실행 설계(민옥 협의)에서 정한다. (7/27 검토 승인 — 확인 #9 해소.)
- R의 조작적 의미 한정: "그 시점 a가 자기 발화 사슬/파라메트릭 표상에서 인출 가능" —
  내면화 전체의 증명이 아니다(§2-2의 TR̂ 한정과 합치).
- 회고 3원칙 계승(어기면 측정 오염): ① 본 토론 오염 금지(사후 replay 사본 위에서만)
  ② **open 정본** — pointed는 질문 자체가 팩트를 재주입하므로 오염 정량화 실험 전용
  ③ "이유" 답변은 사후 합리화로 취급, 집계 금지.
- α̂, β̂는 §2-1 분할표의 표본 비율. 표본 설계(능동 표본추출·MC 팔)는 부록 §7-5.
- **recall.py는 민옥 파일** — 본 절은 측정 요구사항의 명세이고, 구현·변경은 §8-G3의
  확장 요청으로만 진행한다. **요청은 개인 DM이 아니라 보드 공개 협의 안건으로 발신**하며
  (7/27 검토 확정 — 확인 #5 해소), 요청 범위를 명시한다: ① 비보유자 대상 open 프로브
  ② (a,f) 단위 결과 산출 ③ prompt_hash 전수 검증 유지 ④ judge_fact 재사용(잣대 단일화)
  ⑤ **구현 주체는 민옥**(본 설계는 요구사항까지만).

## 6. 사전고정 판별표 (초안 — **커밋 = 고정**)

> 정식 데이터(미니 H2 이후 실호출) 확인 **전에** 고정 커밋한다 — 동결 범위는 이 절만이
> 아니라 **문서 전체(v1.0, 최소 §§2–6 + §7-2 + §8)** 다(헤더 참조). 이후 변경은 append
> 전용. 데모·픽스처(ESA)에 돌리는 것은 허용하되 산출물에 "탐색적 — 정식 판정은 실호출
> 재실행분에서"를 의무 명기한다(FACTCLOCK §6 표기 규칙 계승).

### H-T1. 전달 폭 × 소실 hazard — "전달이 복구 경로인가"

동기: 종말부 침묵 3건의 재해석 — B=0이라 복구 경로가 부재했던 것인가. §2-0-(iii)에 의해
이 가설은 기계적으로 구체적이다: 롤링 창 생태에서 B(f) = f를 실어 나르는 **독립 운반 사슬의
수**이고, B=0이면 자기 사슬 하나뿐이라 한 번의 침묵이 곧 소멸이다.

- 모집단: 도입된 low-prior 팩트(전 밴드 병기), fact-clock 사망/검열 사건(w=0·w=1 병렬 —
  FACTCLOCK 설계 원칙 2 그대로).
- **미래 정보 누출(불멸 시간 편향) 방어 — 필수 (7/27 검토 확정, 확인 #3·#8 해소)**:
  B(f)를 run 전체(토론 종료 후) 집계값으로 쓰면 오래 생존한 팩트일수록 전달 기회가 많아
  B가 기계적으로 커진다 — "전달되어서 덜 소실됐다"와 "덜 소실됐기 때문에 전달될 시간이
  있었다"를 분리할 수 없다. **현재 hazard의 예측에는 과거 전달만 쓴다**:
  - **B_pre(f, u)** = age u **직전까지**(엄격히 u 미만 시점) f를 노출 선행 언급(엄격 규칙
    u≥1, §3-2)한 비보유자 수 — 시변·과거 한정 전달 폭.
  - **주판별**: 각 age u에서, at-risk 팩트를 **B_pre(f,u)=0 vs B_pre(f,u)≥1** 로 나눠
    그 age의 소실 hazard를 비교한다. age별 층화 비교를 기본으로 하고 층 합산(CMH 방식)
    비율을 병기한다.
  - 연속형 log(1+B_pre)는 회귀(§7-2)의 병기 지표. (v0.2의 랜드마크 규칙 B_L은 시변
    B_pre 주지표로 **대체·폐기** — 랜드마크는 L 선택 자의성이 남고, 현 규모(라운드 3~4)
    에선 판정 구간도 부족하다.)

| 관측 패턴 | 지지 해석 |
|---|---|
| ⓐ B_pre≥1 층에서 hazard 유의미하게 낮음 | **전달 = 복구·정착 경로** — 그 시점까지 받아 말한 에이전트가 존재하는 팩트는 침묵에서 복귀할 경로가 있다. 종말부 침묵 재해석 지지 |
| ⓑ 차이 없음 | 전달 폭은 소실과 독립 — 발화 중복은 정착에 기여하지 않음(장부 v0의 "재주입=복구" 가정에 경고) |
| ⓒ B_pre≥1 층에서 hazard 높음 | 역설 신호 — 내생성 경합 해석(논쟁적 팩트일수록 널리 언급되고 또 잘 버려짐)을 우선 검토, 단독 결론 금지 |

- w=0/w=1 갈림 시 **둘 다 보고하고 갈림 자체를 결과로 기술**(단일 결론 강제 금지 —
  FACTCLOCK §5 규칙 그대로).

### H-T2. 담화 전진 × 전달의 상호작용

- 전진 점수 = 라운드 r의 1 − J(r, r−1), J = 직전 라운드 발화와의 문자 2-그램 자카드
  (discourse_progression PREREG_v0.2 §1의 조작적 정의를 **그대로 재사용**, 재정의 금지).
- **주판별 (7/27 검토 확정)**: §7-2 획득 방향 이산시간 hazard 회귀의 **전진 점수 계수
  β₄의 부호·신뢰구간** — at_risk 크기·run 클러스터·공변량을 동시에 통제하는 정식 판정.
- **보조 판별(비모수)**: 전이 풀링에서 전진 점수(r)와 **획득률 acquisitions(r) /
  at_risk(r)** 의 스피어만 ρ_s. **at_risk(r)=0인 전이는 제외.** (획득 "수"를 쓰면 후반의
  미획득 쌍 감소에 기계적으로 끌려간다 — 분모 필수.)
- 두 판별의 방향이 갈리면 w=0/w=1 규칙과 동일하게 **둘 다 보고하고 갈림을 결과로 기술**한다.
  아래 표의 ρ는 β₄·ρ_s가 합의하는 방향을 뜻한다.

| 관측 패턴 | 지지 해석 |
|---|---|
| ⓐ ρ < 0 | **전진이 전달 창을 닫는다** — 화제가 앞으로 가면 남의 팩트를 받아 말할 기회가 사라진다. 전진 성분의 소실 기전에 전달 차단 경로 추가 |
| ⓑ ρ > 0 | **전진이 전달을 운반한다** — 새 화제 도입 자체가 팩트 이동의 수레. 전진=소실이라는 단면 해석에 반례 |
| ⓒ ρ ≈ 0 | 두 축 독립 — 전진 가설과 전달 관문은 별개 기전으로 각자 보고 |

### 공통 강등·무승부 규칙

1. 귀속 kappa 하한 미달 → 두 가설 모두 판정 유보, 탐색적 보고만(§4 필수 조항).
2. TR̂(층 2 결합 지표)는 α·β 표본 구간을 반영한 **구간으로 보고**하고, 구간이 판별 기준을
   걸치면 **무승부** — 표본 추가(§7-5) 전에는 결론을 쓰지 않는다.
3. 결과가 어느 패턴이든 **침묵 금지** — 불성립·무승부도 그대로 보고한다(PREREG_v0.2 P4 관례).

## 7. ML 개선 부록 (우선순위·거버넌스 구분)

| # | 항목 | 비용 | 거버넌스 | 지위 |
|---|---|---|---|---|
| 1 | 기본 confidence(일치도 기반) + Dawid-Skene(조건부) | 0 | 분석층 전용(사양 충돌 0) | 기본 confidence = **본 문서 명세** / DS = **탐색적 부록으로 강등**(7/27 검토) |
| 2 | 이산시간 hazard 회귀 + run 랜덤효과 | 0 | 분석층 전용 | **본 문서 명세** |
| 3 | 임베딩 2단 판정 | 절감 레버 | **측정기 변경 = 보드 확정 필요** | 보드 안건(이미 열린 질문) |
| 4 | 카나리아 팩트 | 소 | **데이터 변경 = 리더 사안** | 보드 안건 |
| 5 | MC 회고 프로브 + 능동 표본추출 | 층 2 실행 시 | 민옥 협의(recall 확장) | 층 2 실행 시점 |
| 6 | 전달 그래프·확산 모델 | — | — | **보류**(현 규모 라운드 3~4에 과잉, 토폴로지 실험과 접속 시) |

### 7-1. 판정 confidence — 기본은 일치도, DS는 탐색적 부록 (비용 0 · 사양 충돌 0)

- 입력: 보존된 `votes[]`(팩트×stage당 n_votes=3, 각 표에 status·agents_mentioning) — 이미
  파일에 있다. **다수결이 정본**인 것은 불변, 이것은 분석층의 재해석이다.
- **기본 confidence(정본 명세)** — 모형 가정 없는 일치도 지표 4종:
  ① status 3/3 만장일치 여부 ② 2/3 다수결 여부(불일치 존재 플래그)
  ③ `agents_mentioning`의 표 간 pairwise agreement(또는 Jaccard)
  ④ 사람 귀속 라벨(패키지 B)과의 kappa(§4와 동일 소스).
  층 1 민감도 분석(저신뢰 항목 제외 시 B·TSR가 움직이는가)과 층 2 진단 표본 선정(§7-5)은
  이 4종으로 한다.
- **Dawid-Skene은 탐색적 부록으로 강등(7/27 검토)**: DS는 표들을 서로 다른 독립 잡음
  평가자로 가정하는데, 현행 3표는 **동일 모델(Sonnet)·temp 0의 반복 vote**라 독립성·식별
  가능성이 의심된다(불일치가 희소하면 혼동행렬이 식별되지 않는다). 반복 호출 간 충분한
  불일치와 식별 가능성이 **데이터에서 확인된 경우에만** 부록 분석으로 수행하고, 정식
  confidence 산출법으로 쓰지 않는다.
- 산출물은 분석 보고서 전용 — 파일 계약 5종 무변경.

### 7-2. 이산시간 hazard 회귀 + run 랜덤효과 (비용 0)

민옥 데모의 자인 한계("전이 27개 9런 비독립")를 해결하는 정식 모형. 팩트×age 전개 데이터에:

> logit h(f, t) = α_t + β₁·log(1+B_pre(f,t)) + β₂·1[low-prior] + β₂′·prior.score +
> β₃·critical + β₄·전진점수(t) + β₅·1[ledger on] + u_run,  u_run ~ N(0, σ²)

- **β₁의 B_pre(f,t)는 시변·과거 한정**(§6 H-T1과 동일 정의 — age t 미만 시점까지의 노출
  선행 엄격 획득 수) — 미래 정보 누출 방어. 이분형 1[B_pre≥1] 감도 분석 병기.
- prior는 밴드 더미(β₂)와 **연속값(β₂′)을 병기**한다(§3-5 — 층화 경계의 자의성 방어).
- α_t = age 고정효과(fact-clock 생명표의 회귀 형태), u_run = run 랜덤효과(클러스터 해결).
- H-T1(β₁)·H-T2(β₄) 공변량 동시 투입 — 판별표의 단변량 판정을 보완하는 병기 지표.
- 획득 방향(h_acq)에도 같은 골격을 대칭 적용하되, 공변량에 **시변 노출 X(a,f,t)·누적 노출
  용량 E(a,f,t)**(§3-3)를 추가한다(재노출 용량-반응이 잡히면 전달의 기전 증거).

### 7-3 ~ 7-6. 보드·리더·협의 사안 (본 문서는 제안 지위만)

- **7-3 임베딩 2단 판정**: judge가 비용 ~90% — 1단 임베딩 스크리닝 + 2단 judge. **측정기
  변경이므로 보드 확정 전 도입 금지.** 임계값은 패키지 B 사람 라벨 ROC로, 선정 절차 자체를
  사전고정한다(데이터 보고 임계값 고르기 금지).
- **7-4 카나리아 팩트**: prior=0이 보장되는 허구 디테일을 주입해 β(침묵 획득률)를
  준-실측으로 격상. **데이터 변경 = 리더 사안.** 현저성(카나리아가 눈에 띄어 과대 전달)
  통제를 제안서에 명시할 것.
- **7-5 층 2 표본 설계 — 확률표본 정본 + 능동 표본은 진단 보조 (7/27 검토 확정)**:
  - **α·β 주추정 = 확률표본**: S=1(언급)·S=0(비언급) 층 각각에서 **층화 무작위 표본** —
    α·β가 층 1 모집단을 대표해야 TR̂ 보정식이 성립한다.
  - **능동 표본추출(층 1 confidence 낮은 쌍에 예산 집중)은 진단용 보조 표본** — 주추정의
    단순 비율에 합산 금지. 능동 표본을 보정식에 포함하려면 **선택확률을 기록하고 IPW 등
    가중 추정**을 쓴다.
  - 결합 규칙: 동일 목표 모집단끼리만(TSR_low ↔ α_low·β_low — §2-2).
  - TR̂는 구간 보고 + 무승부 규칙(§6). 민옥 open/pointed AB 설계에 **MC 팔 추가를 제안**
    (open 정본 지위는 불변).
- **7-6 전달 그래프·확산 모델**: 보류. 토폴로지 실험과 접속되는 시점에 재론.
