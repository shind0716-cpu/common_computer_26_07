## §1 식별 전략 — hazard 회귀에 ledger를 넣을 때의 3규칙

1. **inject 계수는 팔 안에서 식별 불가.** v0에서 inject(r)은 "r−1 소실"의 결정론적
   함수(전량 재주입) — 팔 내 회귀에서 inject는 직전 사망 상태와 100% 공선이다.
   장부 효과의 식별은 **오직 팔 간(off vs v0) 위험집합 정렬 비교**: r−1 소실 팩트끼리
   (v0=전원 주입, off=전원 비주입) r에서의 재생을 비교한다.
2. **깨끗한 비교는 첫 주입 라운드(r=2)뿐.** r≥3의 위험집합은 이미 처치(라운드 2 주입)의
   산물 — 처치 후 변수 조건화다. r=2를 주비교로, r≥3은 위험집합 크기 병기 + 탐색적 강등.
3. **"같은 seed"는 생성 노이즈를 통제하지 않는다.** seed는 좌석·배분만 고정, temp 1.2
   생성은 라운드 1부터 팔 간 분기(OpenAI seed는 best-effort). n=1 쌍의 FAR 차이는
   장부 효과와 run 노이즈를 구분 못 한다 — 파일럿 결과는 방향·기전 관찰까지만.

## §2 tp1 실측(7/27)의 설계 반영 6건

| # | 실측 | 규칙화 |
|---|---|---|
| R1 | prior_suspect 3건 전부 stance_support 의역 거짓양성 | 오분류율 α·β는 **팩트 유형별 층화 추정** (단일 상수 가정 폐기). stance_support는 추적 정본 제외(v2 안건 유지) |
| R2 | 엄격 u≥1 없었으면 획득 절반이 부풀림(u=0 경계) | 층2 능동 표본추출의 **1순위 층 = u=0 경계 쌍** (추상적 "저confidence"보다 실측 근거 우선) |
| R3 | fact_car_04 발화 관문 사망 → 전달 도달 불가 | 관문은 경쟁 위험 구조 — **발화 사망 팩트는 전달 분모에서 음영 제외** 명문화 (다상태 풀 모형은 현 규모 과잉, 보류) |
| R4 | carkey 엄격 획득 6건 전부 critical counter_evidence | EPV 제약 하 공변량 우선순위: **태그·critical 1순위**, B_pre·전진 2순위, 나머지 강등 |
| R5 | ESA TSR 0.236 vs carkey 0.095 (2.5배) | 단일 이슈 일반화 금지 — 정식 조건에 **이슈 ≥2 + 이슈 효과항** |
| R6 | carkey 획득이 τ=r4 수렴 국면 편중 | 전달 강도는 담화 국면 시변 — H-T2(전진×전달) 지지 방향, **rounds 수 = 관측창** 민감도 필요 |

## §3 정식 실행 최소 조건 (제안 — 동기화 확정 대상)

- **팔당 run n ≥ 3** (run 랜덤효과 분산 추정 최소치; n=1이면 랜덤효과 모형 표기 금지)
- **이슈 ≥ 2** (R5)
- **공변량 수 ≤ 사건 수/10** (EPV 규칙; 미달 시 단변량+층화만 보고)
- **rounds 민감도**: 정식에서 rounds 3/4 두 조건 또는 종말부 검열 규칙 명시(FACTCLOCK 이식)

## §4 ML 항목 절차 조항

- **능동 표본추출**: 층 정의(1순위 u=0 경계, 2순위 저agreement) + **포함확률 역수 가중
  (HT)으로만 α·β 집계** — 가중 없는 능동 추출은 보정식 TR̂을 편향시킨다.
- **agreement 기반 confidence**: temp0 반복 3표는 독립이 아니다 — 만장일치율은
  노이즈 **하한 지표**이지 보정된 확률이 아님을 모든 표에 병기. 사람 kappa가 앵커.
- **임베딩 2단 판정·카나리아 팩트**: 게이트 표기 유지(각각 보드 확정·리더 사안) —
  이 메모는 절차만 참조, 도입 판단 없음.

## §5 봉인

- **순환 방지**: 파일럿(tp1·h2p)이 시사한 가설은 정식 실행 전 append 등록해야만 판별
  대상이 된다. 등록 없는 사후 패턴은 전부 "추가 관찰" 지위.
- **결과변수 잠정성**: SURVIVING(FAR 수식)은 잠정 — 확정 시 본 메모 의존 수치 전부
  재산출 대상임을 병기.
