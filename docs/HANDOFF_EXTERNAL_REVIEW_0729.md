# 핸드오프 — 계기 점검 결과를 외부 리뷰 자료로 만들기 (2026-07-29)

## 1. 임무

오늘(7/29) 실행한 **판정기 계기 점검 4건(H1~H4)**을, 우리 프로젝트를 전혀 모르는 외부
리뷰어(ChatGPT 등)가 읽고 반박할 수 있는 **자기완결 문서 1편**으로 만든다. 7/28에 같은
방식으로 리뷰받은 전례가 있다(팀 메모리 「논문의 비약에 대항한 실험들 — 확인된 것과 아직
가설인 것」 → ChatGPT 비판 리뷰 수신 → 그 리뷰가 오늘 실험들의 출발점이 됨).

**지위**: 초안. 게시·외부 전달은 요한 문면 승인 후.

## 2. 리뷰받으려는 대상

한 문장으로: **"우리 측정 도구(LLM judge)가 우리 발견을 만들어낸 것 아닌가"** 라는 자기
의심을, 도구를 직접 재서 검사한 결과.

이건 논문 비판 자료가 아니라 **자기 파이프라인 감사 자료**다. 리뷰어에게도 그렇게 제시할 것 —
"우리 주장을 검증해달라"가 아니라 "이 감사가 충분한가, 결론이 과한가"를 묻는 문서다.

## 3. 오늘 결과 (문서에 들어갈 수치 — 원자료에서 재확인 권장)

전부 carkey 이슈(허구 팩트 12개), 파일럿 판정기(gpt-5.4-mini·temp 0), 단일 run.
**예측은 전부 실행 전에 대화·스크립트 상수에 기록됨.**

### H1 재판정 일관성 (300콜)
tp1 발화 로그는 그대로 두고 **판정만 n=5로 재실행**(seed 변경). 12팩트 × 5스테이지 = 60쌍.
- 예측: 불일치율이 stage와 함께 단조 증가 → **미결**(stage별 0/8/0/8/17%, stage당 12쌍이라 0~2건 차이)
- 전체 표 분열: **4/60 = 7%** (같은 입력엔 대체로 일관)
- tp1 원판정(n=1) 대비: 이진 뒤집힘 2/60, 귀속 집합 불일치 4/60
- **핵심**: 불안정 8쌍이 전부 `fact_car_02`·`03`·`04` 세 팩트에 몰림 = 7/28에 "특이 관측"이라며
  보고한 팩트들과 일치
- **가장 강한 단일 증거**: `fact_car_04` stage 0 — 원판정 False, 재판정 **5:0 True**.
  7/28에 "보유자가 r0에 발화조차 안 해 즉시 사망 · never_exposed 6쌍 · 4관문 연쇄 첫 실물"로
  보고한 사례가 뒤집힘. 뒤집히면 타임라인이 ADDDD→SDDDD가 되고 TSR 분모(음영 쌍)까지 바뀜
- `fact_car_02` stage 3도 True→False — 7/28 보고한 resurgence 1건 소멸

### H2 추상도-검출 곡선 (12+144콜)
팩트별 4단 표현 사다리를 temp 0으로 **한 번 생성해 고정**하고, 동일 캐리어 문장에 넣어 판정.
- 예측: 단조 감소, 3단에서 급락 → **확인**

| 단 | 검출률 | 원문 근접도 |
|---|---|---|
| 1 원문 그대로 | 100% | 1.000 |
| 2 어휘 치환(구체 유지) | 100% | 0.641 |
| 3 요지 압축 | **42%** | 0.345 |
| 4 상위 개념 | 22% | 0.027 |

- 부수: 근접도-검출 용량반응 — 0~0.2:19% / 0.2~0.4:40% / 0.4~0.6:82% / 0.6+:100%. 전이 구간 0.3~0.5
- 표 분열 48쌍 중 1건 (같은 입력엔 일관)

### H3 조건 의존 판정 오차 (LLM 0 — h2p off/v0 로그 재분석)
"언급"으로 판정된 발화가 팩트 원문에 얼마나 가까운지(문자 3-gram containment)를 팔별 비교.
- 예측: v0 팔이 더 축자적 → **팔 수준 기각** (off 0.548 vs v0 0.524)
- 그러나 기전은 확인: v0 내 **주입 경험 팩트 0.769 vs 미주입 0.504** (n=16 vs 198)
- 해석: 팔 평균이 안 움직인 건 부재가 아니라 **저용량**(주입 r3 2건). 장부 공격성·요약 채널로
  용량이 오르면 팔 수준 오염 가능 → 차분 설계 방어선은 **용량 의존적**
- 부수 1: 근접도가 stage 0에 0.846 → stage 1에 0.506으로 **계단 하락 후 평평**(0.520·0.500).
  과제 전환 경계와 일치(저자 프롬프트: r0="모든 팩트를 언급하라", r1+="한 단락으로 갱신")
- 부수 2: 판정 임계값 부재 — 검출된 것의 최소 근접도 0.000, 미검출된 것의 최대 0.733,
  겹침 구간 19~28%(단, 대부분은 어휘만 겹친 진짜 비언급이라 **오류율이 아니라 상한**)

### H4 prior 구성과 누출 (LLM 0 — 기존 산출물 재분석)
- 예측: 누출이 known=True 팩트에 몰림 → **기각**. resurgence 전건이 known=False
  (esa 2/2, carkey 3/3), prior_suspect는 완전 허구 이슈(carkey 3)에만, esa 0
- 부수 정정: **esa도 known=True가 12개 중 1개** — "esa는 상식형이 섞여 열려 있다"는 앞선
  진술은 과했음

## 5. 반드시 지킬 것 (위반 시 문서가 무효)

- **과대 의미 부여 금지** (7/28 요한 교정): 단일 run·단일 이슈·파일럿 판정기다. "가설 확인/
  기각" 언어는 사전고정 판별표를 통과한 것에만. 이 문서의 톤은 **"계기를 재봤더니 이렇게
  보였다"**까지
- **n=5 다수결은 정답이 아니다**: 원판정과의 비교는 **안정성 측정이지 정오 판정이 아니다.**
  "재판정이 맞다"고 쓰면 안 된다. 우리에게 ground truth는 없고, 그 자리는 사람 라벨
  (패키지 B, κ≥0.60/0.80)이 채워야 한다 — 이 점을 문서에 명시
- **저자 프롬프트(DelibTrace) 전문 인용 금지** — 라이선스 미표기. 구조 서술만
- **회사 데이터 무관**: 이 실험은 전부 실험 트랙 픽스처. 관측 트랙 동결과 무관함을 명시
- **[확인 필요]** carkey 팩트 텍스트를 외부 문서에 실을지 — 안현수 님 제작 후보 시나리오
  (팀 검수 전, 허구)다. 예시로 1~2개만 쓸지, 익명화할지 **요한 판단**을 받고 진행할 것

## 6. 예상 공격 지점 (선제적으로 문서에 적을 것)

1. **표본**: stage당 12쌍. 0/8/0/8/17%는 0~2건 차이 — 단조성 주장 불가. 우리가 먼저 미결로 적었음
2. **"집중" 주장의 강도**: 불안정 3팩트 ∩ 특이 관측 4팩트 = 3. n이 너무 작아 우연 배제 불가.
   팩트마다 난이도가 다르므로 팩트 단위 군집 자체는 예상되는 일이라는 반론도 가능.
   → 방어 가능한 형태는 **"car_04의 5:0 뒤집힘"이라는 단일 사례**이지 집중 통계가 아님
3. **ground truth 부재**: 두 개의 불확실한 측정이 서로 다른 것뿐 아니냐 — 정당한 반론.
   답은 "맞다, 그래서 사람 라벨이 필요하다"
4. **근접도 지표의 지위**: 문자 3-gram containment는 우리가 고른 프록시이며 검증된 의미
   척도가 아니다. 의역 판정과 어휘 중첩은 원래 다른 것
5. **H2 외적 타당도**: 짧은 캐리어 문장 ≠ 실제 긴 단락 발화. 검출 조건이 다를 수 있음
6. **사다리 품질**: 사다리를 LLM이 생성했고 팩트마다 추상도 단계가 균질하지 않음
   (car_04·06은 4단까지 100% 검출 — 추상형에도 고유 내용이 남음)
7. **자기 참조 순환**: 판정기의 오류를 판정기로 쟀다. H2는 표준자(고정 사다리)를 썼으니
   덜하지만, H1은 순수 자기 일관성이라 **일관되게 틀리는 오류는 원리적으로 못 잡는다**
