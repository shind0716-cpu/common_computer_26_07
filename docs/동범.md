## 1. 지금 하는 일 — 3일 미니 스프린트 (7/21 화 ~ 7/23 목)

### 목적
최종 산출물의 **걸어다니는 뼈대(walking skeleton)** 를 미니 규모로 한 바퀴 돌린다.
목표는 실험 결과가 아니라 **"7모듈이 실제로 이어져 돌아간다"는 증거 + 실측 기반 업무 분해표**.

### 왜 이렇게 하는가 (근거)
1. 머리로 짠 업무 분해는 틀린다. 돌려봐야 진짜 업무가 드러난다.
   - 증거: 민옥 님 7/16 파일럿에서 "judge 노이즈가 갭 규모와 맞먹음" 발견 → 돌렸기 때문에 나온 업무(재채점 설계)
2. 금요일 타 팀 공유 자료의 업무 분해표가 **추정이 아니라 실측**이 된다.
3. 데이터 지침 미확정이 장애물이 아니다 — 파일 계약 구조라 로더만 나중에 교체하면 된다.

### 가능하다고 본 근거
- 민옥 님이 이미 미니 E2E 1회 완주 (7/16 Salience Probe) → 0→1이 아니라 1→2
- 저자 코드 공개 (github.com/whr000001/DelibTrace) — 토론 엔진 신규 개발 불필요
- 설계 문서 v0.1 (7/21, 민옥 측) — 7모듈 분해·파일 계약·사다리 확정된 상태에서 출발

### 일정

| 날짜 | 목표 | 할 일 | 완료 기준 |
|---|---|---|---|
| **7/21 화** | 계약 확정 + 재료 | ① 파일 스키마 5종 v0.1 확정 ② 미니 이슈 1건 수작업(팩트 12~15개 + 꼬리표 + critical 라벨) ③ 배분표 작성(8에이전트 비대칭) | 5개 파일이 스키마대로 존재 |
| **7/22 수** | 대조군 완주 (미니 H1) | ④ 토론 엔진 포팅 + 채점기(mini급, temp 0) 연결 ⑤ 바닐라 1회 완주 → 로그 전량 저장 → FAR 4분할 산출 | 라운드별 retention 곡선 숫자 산출 |
| **7/23 목** | 실험군 + 패키징 (미니 H2) | ⑥ Ledger v0 on, 동일 이슈·시드로 1회 → on/off 쌍 비교 ⑦ 결과 패키징 ⑧ 실측 기반 업무 분해표 + 8주 타임라인 보정 | 금요일 공유 자료 완성 |

### 역할 (제안 — 민옥 님 확인 필요)
- **신동범**: 토론 엔진 · 채점기 (측정 파이프라인)
- **민옥**: 스키마 · Ledger v0
- **Claude**: 코드 초안, 스키마 문서화, 분석 스크립트, 자료 패키징

2. 7모듈 실측 기반 업무 분해표

## 5. 기억해둘 핵심 수치 (앵커 논문)

- critical 팩트 소실: System 21.7~72.4% / Agent 60.5~84.8%
- **72%의 정체**: GPT-4.1 · News · fully connected → retention 1.00 → 0.28
- **★ 무상호작용 19.2% vs 토론 67.8%** — 손실은 소통이 만든다
- 살아남은 팩트가 더 추상적 (2.73 vs 2.33, p<0.005)
- 완화책 3종(페르소나·이종화·토폴로지) 전부 실패
