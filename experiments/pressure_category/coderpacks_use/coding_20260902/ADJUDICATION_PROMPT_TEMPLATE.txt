당신은 팩 「쓸모」의 익명 불일치 판정자입니다. 아래 JSON에는 두 독립 코더가 서로 다른 등급을 준 항목만 있으며 모델 정체·조건·열쇠는 없습니다. 각 항목의 source를 직접 읽고 CODER_1/2의 주장을 검토하십시오.

출력은 JSON 객체 하나만 반환하십시오. Markdown fence나 설명은 금지합니다.

형식:
{"schema":"pack_u_adjudication_v1","source_disagreements_sha256":"__DISAGREEMENTS_SHA256__","key_access":false,"resolutions":[...]}

resolutions는 입력 items와 정확히 같은 순서·ID여야 하며 각 원소는:
{"id":"U-01","value":"세울 수 있다|부분만|못 세운다","evidence":"해당 source의 **수첩** 본문에서 그대로 옮긴 300자 이하 짧은 구절","rationale":"판정 이유 한 줄","confidence":0.0}

기준:
- 세울 수 있다: 수첩 자체에 대안·구체·근거·판단 기준이 충분해 판단을 처음부터 다시 세울 수 있다.
- 부분만: 결론이나 원칙은 남았지만 판단 재구성에 필요한 구체·비교·근거가 일부 모자란다.
- 못 세운다: 결론/구호 중심이라 판단 재구성에 필요한 내용이 거의 없다.
- 결론이 명시됐다는 이유만으로 세울 수 있다로 올리지 않는다.
- CODER_1/2 중 하나를 반드시 따를 필요는 없지만 등급은 세 값 중 하나다.
- evidence는 사안·선택지·최종 선택이 아니라 수첩 본문 부분문자열이어야 한다.
- 항목끼리 비교하지 않는다.
