# 원본 공동체 12가 실제로 품고 있는 가치 — 참고용

지위: **근거 자료** (판독 아님. 원본 YAML 을 읽고 그 안의 축을 뽑아 적은 것)
대상: `experiments/scenario_generalization/scenarios/community_living/SCENARIOS_12_V03_DEVELOPMENT.yaml`
왜: 압박 재료를 열 벌 지으면서 쓴 가치 풀(접근성·편의·안전·평온·위생·이동권·여유·예측·시간)이
원본에서 나온 것인지 내가 씌운 것인지 확인하려고. 결론부터 — **절반은 씌운 것이다.**

## 1. 무대별로 원본이 실제로 맞세우는 축

원본 열둘은 모두 같은 얼개다: 당사자 둘, 각자의 필요, 각자 이미 해 본 것, 그리고 대안 자원 하나.
그래서 축은 **두 당사자의 필요**로 나온다.

| 무대 | 한쪽 필요 | 다른쪽 필요 |
|---|---|---|
| 길고양이 급식 | 고양이가 끼니를 거르지 않는 것 | 남은 먹이·보행로 |
| 일반 공용 주차 | 출발 전 장비 싣는 준비 | 밤늦은 귀가에 댈 자리 |
| 층간 생활소음 | 아이의 저녁 활동 | 교대근무자의 저녁 수면 |
| 재활용 보관실 | 늦은 귀가 시각에 배출 | 밤 소리·통로 적치 |
| 공용 화단 | 계절마다 이어지는 꽃 | 출입로 시야와 통행 폭 |
| 빈 텃밭 | 물길이 이어진 인접 구획의 효율 | 처음 신청한 사람의 기회 |
| 셔틀 노선 | 병원·시장에 서는 것 | 역 도착 시각과 환승 예측 |
| 임산부 우선 주차석 | 예측 못 하는 귀가 시각의 우선 | 무거운 장비 하역 거리 |
| 공동 흡연 구역 | 비·눈에도 쓸 지붕 | 복도 환기 시 연기 |
| 택배 보관 선반 | 늦게 수령해도 두는 기간 | 자주 받는 사람의 자리 |
| 공용 세탁실 | 아침 출근 전 건조 마감 | 주말 세 회분의 대기 |
| 주민 공용실 | 같은 책상과 화면 | 의자 치운 바닥과 환기 |

## 2. 원본에서 자연히 나오는 가치 낱말

무대 둘 이상에 걸치는 것만 적는다.

| 가치 | 나오는 무대 |
|---|---|
| **자리·여유** | 주차 · 택배 · 세탁 · 공용실 |
| **평온(소리·냄새·수면)** | 층간소음 · 재활용 · 흡연 |
| **통행·보행** | 캣맘 · 화단 · 재활용 |
| **시각·마감** | 셔틀 · 세탁 · 재활용 |
| **예측 가능성** | 셔틀 · 임산부 주차석 · 주차 |
| **기회·공정** | 텃밭 · 임산부 주차석 · 택배 · 공용실 |
| **접근 거리** | 셔틀 · 임산부 주차석 · 흡연 |
| **위생** | 캣맘 · 재활용 |
| **설비·조건** | 공용실 · 흡연(지붕) · 세탁(건조) |

## 3. 내가 쓴 풀과 대조

| 내 풀 | 원본 근거 |
|---|---|
| 접근성 | 있음 (셔틀·임산부·흡연) |
| 편의 | 약함 — 원본에서는 '준비 시간'·'지붕' 같은 개별 조건이지 한 축이 아니다 |
| 안전 | 화단(시야) 하나뿐. 나머지 아홉 무대의 안전은 **내가 만든 것** |
| 평온 | 있음 (층간소음·재활용·흡연) |
| 위생 | 있음 (캣맘·재활용) |
| 이동권 | 있음 (캣맘·화단·재활용) |
| 여유 | 있음 (주차·택배·세탁·공용실) — 원본에서 가장 굵은 축인데 내 풀에서는 5무대뿐 |
| 예측 | 있음 (셔틀·임산부·주차) |
| 시간 | 있음 (셔틀·세탁) |

**내 풀에 없는데 원본에 굵게 있는 것: 기회·공정.**
텃밭·임산부 주차석·택배·공용실 넷이 전부 "누가 먼저, 얼마나 쓰나"다. 나는 그 넷 중 택배를
자리 문제로 비틀었고 나머지 셋은 아예 안 지었다. 그러면서 공정 축이 통째로 빠졌다.

**내 풀에 없는데 원본에 있는 것: 수면, 설비 조건, 하역 부담.**

## 4. 왜 어긋났나

원본 열둘은 가치를 **사람에게** 붙인다 — "이 사람에게 필요한 것". 규칙 ⑤ 는 가치를 **선택지에**
붙이라고 요구한다. 둘이 정면으로 어긋난다.

캣맘에서 실측으로 걸린 것이 그 어긋남이었다(LIMITS_cat_feeding_2026-08-25.md). '돌봄'은 주민
모임에게 필요한 것이라 급식 장소를 옮겨도 따라가고, 그래서 모델이 "두 곳 모두 가능"이라며 그
축을 버렸다. 원본의 축을 그대로 쓰면 같은 일이 매번 난다.

그래서 나는 무대마다 선택지를 장소·시간·배치로 바꿔 축을 선택지에 붙였다. 그 대가로
authored 비중이 커졌고(세탁 12/12, 택배 10/12), 원본이 굵게 다루는 **공정** 축이 사라졌다.

## 5. 참고로 남기는 두 갈래

**갈래 하나 — 지금대로 간다.** 선택지를 사물로 잡고 가치를 사물에 붙인다. 규칙 ⑤ 가 서고
카테고리 생존이 깨끗하게 측정된다. 대신 공정·수면처럼 사람에게 붙는 가치는 못 잰다.

**갈래 둘 — 사람에게 붙는 가치를 재는 다른 계기를 만든다.** 지금 계기(카테고리 생존 = 마지막
수첩에 그 카테고리 사실의 표식이 남는가)는 사물 축을 전제한다. 공정을 재려면 "누구의 몫이
수첩에서 먼저 사라지는가"를 세는 다른 판독이 필요하다 — 사실 표식이 아니라 당사자 표식을
세는 쪽이다. 원본 열둘은 그쪽 계기에 훨씬 잘 맞는다.

이 문서는 어느 갈래도 고르지 않는다. 지금 재료 열 벌은 갈래 하나로 지어져 있고, 원본이
그쪽에 절반만 맞는다는 사실을 적어 둘 뿐이다.
