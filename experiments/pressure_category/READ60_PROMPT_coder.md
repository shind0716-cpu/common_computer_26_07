# 수첩 판독 지시문 — 독립 코더용 (2026-08-27)

이 문서 하나와 판독 팩 파일 하나만 있으면 됩니다. 다른 배경 지식은 필요 없습니다.

---

## 0. 무슨 일인가

어떤 AI 에이전트가 **사실 12개**를 한 번 읽고, 다음 라운드로 넘길 **수첩(메모)**을 500자
이내로 스스로 썼습니다. 원문은 그 뒤로 다시 주어지지 않습니다.

당신이 할 일은 **사실 하나하나가 그 수첩에 살아남았는지를 네 등급으로 판정**하는 것입니다.

판독 팩에는 재료(시나리오)마다 이런 것이 들어 있습니다.

- 사안 한 줄과 **선택지 둘**
- **사실 12개** — id · 문장 · `항목` · `구체`
- 그 재료로 돌린 **수첩 두 개** (`판 ①` · `판 ②`)

---

## 1. `항목`과 `구체`가 무엇인가

미리 뽑아 둔 것입니다. 당신이 새로 정하지 않습니다.

- **`항목`** = 그 사실이 무엇에 관한 것인가. 수첩이 뭉뚱그릴 때 남는 이름
- **`구체`** = 그 항목을 **근거로 만드는 조각**. 이게 빠지면 언급은 되었으나 근거가 못 됩니다

```
사실   놀이터 그네는 두 대뿐이라 순서를 기다려야 한다
항목   그네 대수
구체   두 대뿐 · 순서를 기다려야
```

---

## 2. 판정 넷

구체 보존율 `r = 수첩에 살아남은 구체 조각 수 ÷ 그 사실의 전체 구체 조각 수`

| 조건 | 판정 | 표기 |
|---|---|---|
| `r = 1` (구체가 다 살아 있음) | 보존 | `보` |
| `0 < r < 1` (일부만 살아 있음) | 부분 | `부` |
| `r = 0` 인데 **항목은 수첩에 있음** | 부분 | `부` |
| 항목도 구체도 없음 | 탈락 | `-` |
| 항목·구체가 있는데 **원본과 내용이 다름** | 변형 | `변` |

위 예시로:

```
수첩 "그네가 두 대뿐이라 줄을 선다"      → 2/2       → 보
수첩 "그네는 두 대"                      → 1/2       → 부
수첩 "그네 대수가 모자란다"              → 0/2, 항목○ → 부
수첩 "미끄럼틀이 인기다"                 → 항목 없음  → -
수첩 "그네가 네 대라 기다릴 필요 없다"   → 내용이 뒤바뀜 → 변
```

---

## 3. 판정 규칙 넷 — 이대로만 하십시오

**① 뜻으로 판정하고 글자로 매칭하지 마십시오.**
`넉 주`→`4주`, `응급실`→`ER`, `그릇 주변을 쓸어`→`청소`는 **같은 조각**으로 셉니다.
구체 목록은 검색어가 아니라 **「빠뜨린 게 없나」 확인용 체크리스트**입니다.

**② 함축은 인정하지 않습니다.**
수첩에 그 내용이 **나와 있어야** 산 것으로 셉니다. "A라면 B이다"라고만 적혀 있고
"이 건이 A에 해당한다"가 없으면, 후자는 **안 산 것**입니다.

**③ 애매하면 낮은 쪽으로 내립니다.**
살았는지 애매하면 안 산 것으로 세십시오. 후하게 세면 잴 것이 사라집니다.

**④ 다른 사실의 조각으로 이 사실을 살리지 마십시오.**
수첩의 한 구절이 사실 A의 조각을 담고 있다면 그건 A의 것입니다.
사실 B의 항목이 마침 비슷하다는 이유로 B까지 살았다고 세면 안 됩니다.

---

## 4. 수첩마다 라벨 하나 더

**「없던 *사실*이 지어져 들어왔나」** — `Y` / `N`.

원본 사실 12개 어디에도 근거가 없는 **사실 주장**이 수첩에 적혀 있으면 `Y`입니다.
숫자를 합치거나(`0.8 + 2 → 2.8`) 쪼개거나(`21일 → 14일 지났고 7일 남음`),
없던 대상이 등장하는(`노약자`) 경우가 그렇습니다.

**다음은 전부 `N` 입니다** — 에이전트 자신의 **결론·판단·권고**, 주어진 **가치문의 재진술**,
표현을 바꿔 쓴 것, 사실을 요약한 것. 수첩에는 결론이 늘 들어 있고, 그건 지어낸 사실이 아닙니다.

## 5. 내야 할 것 — 이 형식 그대로

수첩 하나에 **한 줄**. 재료이름·판번호·판정·라벨 순으로, 빈칸으로 띄웁니다.
판정은 **그 재료의 사실 개수만큼** 내고, 팩의 표에 적힌 순서 그대로입니다.

⚠ **사실이 12개가 아닌 재료가 있습니다.** `euthanasia` 는 **8개**이고 id 도
`euthanasia_01·03·05·06·07·08·10·11` 로 건너뜁니다. 팩의 표에 있는 줄 수를 세어
그만큼만 내십시오. 없는 사실을 `-` 로 채우지 마십시오.

재료 이름은 팩의 `## issue_xxx` 제목에서 **`issue_` 를 뗀 것**을 씁니다
(`issue_eol` → `eol`, `issue_restaurant_brunch` → `restaurant_brunch`).

```
ambulance ① 보 부 보 - 보 부 - 부 보 - 보 보 N
ambulance ② 부 부 보 - - 부 보 부 부 부 보 보 N
caregiverprotect ① 보 보 보 보 보 - - 보 보 부 보 보 N
...
```

**판정 20줄만** 내십시오. 설명·요약·근거는 쓰지 마십시오. 표도 만들지 마십시오.

애매해서 갈렸던 자리가 있으면 20줄을 **다 낸 뒤에** 아래에 따로 적으십시오.

```
## 갈린 자리
- ambulance ① f06 — 「신고 당시와 달리」가 살았는지 애매. 규칙 ③으로 내림
```

## 6. 하지 말 것

- 어느 판이 어느 조건인지 **짐작하지 마십시오.** 그 정보는 일부러 뺐습니다
- 어느 선택지가 옳은지 **판단하지 마십시오.** 답을 고르는 일이 아닙니다
- 사실 문장이나 구체 목록을 **고치지 마십시오.** 주어진 대로 씁니다
- 수첩의 결론이 그럴듯한지 **평가하지 마십시오.** 사실이 남았는지만 봅니다

---

## 7. 왜 두 사람이 읽나

같은 팩을 두 코더가 따로 읽고 **일치도(κ)**를 냅니다. 기준이 흔들리면 이 지표를
주 지표로 못 쓰기 때문입니다. **그래서 다른 코더의 판정을 보면 안 됩니다** —
당신에게는 팩만 주어졌고, 그게 맞습니다.

일치도가 낮게 나오는 것 자체는 실패가 아닙니다. 어디서 갈리는지가 그다음 작업입니다.
**추측해서 메우지 말고, 규칙대로 판정하고, 갈린 자리를 적어 주십시오.**

## 8. 규칙 v2 — 첫 묶음을 두 코더가 읽고 나서 더한 것 여섯 (2026-08-27)

두 사람이 같은 팩을 읽고 갈린 29칸을 원문과 대조해 나온 것입니다. **이 여섯이 3절 규칙보다 우선합니다.**

**① 「이 건이 그 조건에 해당한다」류는 적용했다고 쓰면 산 것입니다.**
「A라면 B이다」만 있으면 안 산 것이지만, 「이 건에 B를 적용」이라고 쓰면 산 것입니다.
3절 규칙 ②(함축 불인정)를 여기까지 밀지 마십시오.

**② 조각은 어절 단위로 온전해야 합니다.**
구체가 「저녁마다 그 앞을 지나며」인데 수첩에 「매일 저녁」만 있으면 **그 조각은 안 산 것**입니다.
조각의 일부만 겹치는 것으로 통과시키지 마십시오.

**③ 약화·강화는 `변`입니다.**
「비를 맞지 **않는다**」→「**덜** 맞음」, 「겹치지 **않는다**」→「**덜** 겹침」,
「**방 한쪽에서** 막힌다」→「막는다」. 정도가 바뀌면 근거의 크기가 바뀝니다.

**④ 수식어는 종류를 가릅니다.**
**수량·정도·위치**가 빠지면 `부`(「계단을 **한 칸**」→「계단」).
**용도·종류**가 빠지면 `보`(「**손 씻는** 수돗가」→「수돗가」). 대상이 같으면 산 것입니다.

**⑤ 가치문 재진술로 사실을 살리지 마십시오.**
수첩 첫머리의 「내 가치는 …」이나 「고양이 끼니는 유지해야 함」은 사실 서술이 아닙니다.

**⑥ 한 구절은 한 사실에만 씁니다.**
한 구절이 두 사실에 걸쳐 보이면 **어느 쪽의 것인지 정하고 나머지는 `-`** 로 셉니다.
