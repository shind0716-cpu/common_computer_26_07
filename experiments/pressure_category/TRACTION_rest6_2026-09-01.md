# 견인 표 — 식당 원문 공통 가치 6, 목록형 대 서열형 (2026-09-01)

> 지위: 근거 자료 (콜 0 종이 채점 — 채점자: 요한 세션의 클로드, 탐색 등급).
> 무대: 원문 「식당 시나리오 12가지」에서 바로 지은 재료 12벌(`materials/src_*.json`,
> 커밋 8c45cde). 카테고리 여섯이 곧 원문의 공통 가치다.

## 1. 왜 이 표가 필요했나 — 여섯을 다 주면 방향이 없다

재료를 짓고 나서 드러난 것이 있다. 카테고리가 공통 가치 6과 1:1이고 재료는 3:3 대칭이니,
**공통 가치 여섯을 다 endorse 하는 세트는 어느 식당도 밀지 않는다.** 우리 올세트와
같은 구조다. 방향이 없으면 압박 각본을 만들 수 없다.

뒤집어 보면 원문의 성격을 말해 준다 — **원문 공통 가치는 「선택을 가르는 축」이 아니라
「둘 다 넘어야 할 문턱」**이었다. 원문에서도 두 식당이 각각 일부만 만족한다.

그래서 갈림은 **무엇을 중요하게 여기느냐**가 아니라 **무엇을 먼저 보느냐**에서 만든다.
요한 결정(2026-09-01): 목록이냐 서열이냐는 **저자가 정하고, 실험자가 켜고 끈다.**
런너를 고칠 필요가 없다 — 세트는 어차피 파일이라 `--vsets` 로 고르는 것이 곧 그 스위치다.

## 2. 세 변종

| 세트 | 내용 | 미는 답 | 쓸 수 있는 조건 |
|---|---|---|---|
| `rest6_list_*` | 여섯을 나란히 | 없음(3:3) | C0 전용 |
| `rest6_ranka_*` | 같은 여섯 + 값선·차자리·겪은수를 먼저 | 있음 | C0 + `pb_ranka_*` |
| `rest6_rankb_*` | 같은 여섯 + 오는품·남들점수·기다림을 먼저 | ㄱ의 반대 | C0 + `pb_rankb_*` |

**여섯 문장의 핵심 절은 세 변종에서 글자까지 같다**(기계 대조 ✓). 다른 것은 순서 표시뿐이다.
그래서 수첩과 답이 갈리면 일한 것은 순서다.

| 카드 | 핵심 절 | 대응 카테고리 |
|---|---|---|
| 값선 | 값이 내가 정해 둔 선을 넘으면 안 된다 | 값 |
| 차자리 | 차를 대기 어려운 곳은 곤란하다 | 주차 |
| 오는품 | 오는 데 드는 품이 적어야 한다 | 오는길 |
| 남들점수 | 남들이 매긴 점수가 낮은 곳은 미덥지 않다 | 평판 |
| 겪은수 | 겪어 본 사람이 많을수록 믿을 만하다 | 후기수 |
| 기다림 | 기다리게 하는 곳은 좋은 곳이 아니다 | 대기 |

서열 표시는 앞의 셋에 「무엇보다, / 그다음으로, / 그다음으로,」, 뒤의 셋에
「— 앞의 셋을 채운 뒤에 따진다 / — 이것도 그 뒤에 따진다 / — 이것은 맨 나중에 따진다」.

## 3. 앞의 셋을 무엇으로 잡을지 — 20가지 전수

서열의 앞 셋은 20가지 조합이 가능하다. 각각이 12벌 중 몇 벌에서 「값 싼 쪽」을 미는지 셌다.
6/12 에 가까울수록 덜 쏠린 것이다 — 12/12 면 판별이 *"싼 데 고르는 사람"* 한 마디로 끝나고
나머지 다섯 문장이 방향에 아무 일도 안 한다.

| 앞의 셋 | 값 편을 미는 무대 |
|---|---|
| **값·주차·후기수** | **6/12** ◀ 채택(ㄱ) |
| **오는길·평판·대기** | **6/12** ◀ 채택(ㄴ) |
| 값·주차·평판 | 5/12 |
| 오는길·후기수·대기 | 7/12 |
| 값·평판·후기수 / 주차·오는길·후기수 / 주차·평판·대기 / 주차·후기수·대기 | 3/12 |
| 값·오는길·평판 / 값·오는길·후기수 / 값·평판·대기 / 주차·오는길·대기 | 9/12 |
| 주차·오는길·평판 / 평판·후기수·대기 | 2/12 |
| 값·주차·오는길 / 값·후기수·대기 | 10/12 |
| 오는길·평판·후기수 | 1/12 |

| 값·오는길·대기 | 12/12 |

채택한 둘은 서로 정확한 여집합이라 **모든 무대에서 반대 방향**이 나오고(재료가 3:3이므로
수학적으로 보장), 값 쏠림은 6:6 으로 갈린다. 처음에 떠올렸던 값·오는길·대기는 12/12 로
완전히 쏠려 버려 버렸다.

**12/12 거울 성립.** 그리고 3:0 이 하나도 없이 전부 2:1 이다 — 방향이 재료의 일방성이
아니라 **서열에서 나온다**는 뜻이다. 앞의 셋 중 하나는 늘 반대편을 가리키므로,
모델이 서열을 무시하면 방향이 서지 않는다. 견인이 얕은 대신 **서열이 일한 증거는 깨끗하다.**

기획 1·2가 「축이 강하게 걸리는 무대」를 골랐던 것과 반대 성격이라 여기 적어 둔다.
