# 기계 자가 모델마다 다르게 본다 (2026-09-04)

> 팩 「뜻」(`coderpacks_meaning`)의 열쇠 결합본을 **다시 세었다.** 새 판독을 안 했다.
> 원 보고서 `FINAL_REPORT.md` 는 「모델별 우열로 분해하지 않는다」고 적었다.
> 여기서 가르는 것은 **모델의 우열이 아니라 자의 성질**이다 — 같은 자가 모델마다
> 다르게 보이는가. 원 보고서의 「사후 탐색」 지위와 한계는 그대로 딸려 온다.

## 1. 왜 이 팩인가

팩 점검(`PACKAUDIT.md`) 결과, 지금까지 돌린 열셋 중 **세 모델을 균형 있게 보면서
규모까지 갖춘 것은 이 팩 하나**다(99판 = 이슈 11 × 모델 3 × 조건 3, 594칸).
나머지 깊은 팩은 전부 gpt 하나다.

## 2. 다시 센 것 — 눈금은 「살아있다」만

| 모델 | 사람 「살아있다」 | 그중 기계가 잡음 | **잡은 몫** | 헛짚음 |
|---|---:|---:|---:|---:|
| claude-haiku | 84 | 23 | **27%** | 0 |
| gemini-flash | 105 | 37 | **35%** | 0 |
| gpt | 149 | 78 | **52%** | 0 |

| 조건 | 사람 「살아있다」 | 그중 기계가 잡음 | 잡은 몫 | 헛짚음 |
|---|---:|---:|---:|---:|
| 가치 A | 149 | 79 | **53%** | 0 |
| 신념 C0 | 101 | 33 | **33%** | 0 |
| 신념 압박 | 88 | 26 | **30%** | 0 |

각 칸 198개(판 33 × 갈래 6).

## 3. 무엇이 나오나

**하나 — 자가 모델 격차를 두 배로 부풀린다.**

사람 눈으로 gpt 는 하이쿠의 **1.77배**(149/84)다.
기계로 재면 **3.39배**(78/23)다.

> **기계 표식으로 잰 모델 비교는 gpt 쪽으로 기울어 있다.**

**둘 — 헛짚음이 없다.** 세 모델 다 0이다. 기계가 「있다」 한 칸은 사람도 다 있다고 봤다.
자는 **놓치기만 하고 헛것은 안 잡는다.** 그러니 기계값은 값이 아니라 **하한**이다.

**셋 — 조건에 따라서도 갈린다.** 가치 53% → 신념 30%.
원칙 문장 판에서 자가 더 많이 놓친다.

## 4. 무엇을 고쳐 읽어야 하나

- **기계 표식으로 낸 모델 사이 사실 보존 비교**는 배율이 모델마다 다르므로
  그대로 읽으면 안 된다. 같은 자로 잰 값이라도 **같은 눈금이 아니다.**
- 한 모델 안에서 조건을 견주는 것은 배율이 같으므로 상대 비교가 선다.
- 오늘 `_수첩읽기2/CROSS66.md` 에서 gpt 원칙 66판으로 잰 **0.53배**는
  이 표의 gpt·신념 칸(33%)과 눈금이 다르다 — 저쪽은 뜻2의 「있음」,
  이쪽은 뜻1의 「살아있다」다. 두 값을 섞지 마라.

## 5. 이 표가 못 하는 말

- **모델의 우열이 아니다.** 「살아있다」 개수 차이(gpt 149 · 하이쿠 84)는
  사람 판독이 본 것이고, 그 자체가 모델 순위의 근거로 쓰이려면 별도 설계가 필요하다.
  여기서 쓰는 것은 **같은 사람 판독을 분모로 놓았을 때 자가 얼마를 잡나**뿐이다.
- 원 보고서의 한계가 그대로 딸려 온다 — 코더가 사람이 아니고, Claude 측 최종 코더는
  전송 절단 때문에 두 세션을 고정 범위로 합친 composite 이며, 판정자는 Claude 세 세션이다.
- rep1 만이다. 같은 격자의 rep2·3 은 세 모델 전부 판이 차 있으나 아직 안 읽었다.
