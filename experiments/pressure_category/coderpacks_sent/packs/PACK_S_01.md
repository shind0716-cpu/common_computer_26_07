# 판독 팩 「수첩 문장」 — 01번 묶음 (수첩 8장)

당신은 판독자입니다. 수첩 한 장이 문장으로 쪼개져 있습니다.
문장마다 **갈래 하나**와 **새 내용 여부**를 판정하십시오.

## 갈래 여섯 — 하나만 고른다

| 갈래 | 뜻 |
|---|---|
| **사실** | 처음에 준 사실 열둘 가운데 하나를 옮긴 문장. **말을 바꿔 썼어도 사실이다** |
| **결론** | 어느 쪽을 고르는지, 지금 입장이 무엇인지 |
| **되풀이** | 이 판에 준 문장(위 인용문)을 그대로 또는 바꿔 적은 것 |
| **단서** | 반대편 논거 · 약점 · 양보. 「다만」 「단」 「반면」으로 이어지는 자리 |
| **지시** | 다음에 무엇을 할지, 무엇을 확인할지 자기에게 적어 둔 것 |
| **그밖** | 위 다섯에 안 들어가는 것 |

애매하면 **문장의 주된 일**로 고른다. 한 문장이 사실을 대며 결론을 말하면 **결론**이다.

## 새 내용 — 예 / 아니오

준 사실 열둘과 준 문장, 상황 설명 어디에도 **없던 내용**이 들어갔으면 `예`.
숫자가 바뀌었거나, 없던 수치·사례·일반론이 생겼으면 `예`.
바꿔 말한 것뿐이면 `아니오`.

갈래와 따로 판정한다. **사실이면서 새 내용이 「예」인 문장도 있을 수 있다.**

## 지킬 것

1. 문장 하나씩 따로 본다. 앞 문장 때문에 뒤 문장을 밀지 않는다.
2. 글자가 아니라 뜻으로 읽는다.
3. **근거를 쓰지 않는다.** 표만 채운다. 길게 쓰면 도중에 잘려 수첩이 통째로 날아간다.

## 내는 방법 — 반드시 파일로 쓴다

`Write` 도구로 지시받은 `OUT_S_<번호>.md` 에 담아 내십시오. 화면에 표를 출력하지 마십시오.

```
## N-XX
| 번호 | 갈래 | 새 내용 |
|---|---|---|
| s01 | 사실 | 아니오 |
| s02 | 결론 | 아니오 |
...그 수첩의 마지막 문장까지
```

문장 번호는 팩에 적힌 것을 그대로 씁니다. 빠뜨리지 마십시오.
파일을 쓴 뒤 최종 답변에는 `쓴 파일: <경로> · 수첩 <개수>` 한 줄만 적으십시오.

## N-08

**선택지**: 밤 열 시 마감 · 밤에도 열어 둠

**처음에 준 사실 열둘**

- 늦게 돌아오는 주민은 잠긴 문 앞에서 그대로 돌아선다.
- 밤에도 열려 있으면 귀가 시간에 맞춰 곧장 들를 수 있다.
- 부피 큰 상자는 현관 안에 두기 어려워 다음 날까지 집 안에 쌓인다.
- 밤에 들일 수 있으면 받은 날 바로 내놓게 된다.
- 문이 닫힌 밤에는 봉투가 통로 바닥에 놓여 지나는 길을 좁힌다.
- 밤에도 안으로 들일 수 있으면 봉투가 문 밖에 남지 않는다.
- 문을 닫는 시각이 지나면 그 뒤로는 병 굴러가는 소리가 나지 않는다.
- 밤늦게 병과 캔을 넣는 소리가 아래층 침실까지 닿는다.
- 문을 닫아 두면 밤사이 보관실에 낯선 사람이 들지 않는다.
- 밤에 문이 열려 있는 동안 보관실은 바깥 통로에서 안이 보이지 않는 구석이 된다.
- 낮에 내놓는 것은 분류 표지가 보이는 시간이라 품목이 제자리에 들어간다.
- 밤에 들어간 봉투는 아침에 보면 품목이 섞여 있다.

**이 판에 준 문장**

> 같은 경우는 같게 다루는 것이 옳다. 한 번 정한 것은 지켜질 때 비로소 값이 있다. 받을 몫은 쌓아 온 기여에서 나온다. 한 사람만을 위한 특별한 길은 나머지 모두에게 진 빚이다. 결정은 순서와 방식을 밟아 내리는 것이 옳다. 오늘의 편의는 내일의 선례가 된다.

| 번호 | 문장 | 갈래 | 새 내용 |
|---|---|---|---|
| s01 | 결론: 재활용 보관실은 밤 10시에 닫는 쪽. |  |  |
| s02 | 근거는 공동의 질서·안전·공정성. |  |  |
| s03 | 밤 개방 시 늦은 소음이 아래층 침실에 닿고, 낯선 사람 출입 가능성이 생기며, 봉투가 통로에 놓여 길을 좁힘. |  |  |
