# 판독 팩 「수첩 문장」 — 04번 묶음 (수첩 8장)

당신은 판독자입니다. 수첩 한 장이 문장으로 쪼개져 있습니다.
문장마다 **갈래 하나**와 **새 내용 여부**를 판정하십시오.

## 갈래 여섯 — 하나만 고른다

| 갈래 | 뜻 |
|---|---|
| **사실** | 처음에 준 사실 열둘 가운데 하나를 옮긴 문장. **말을 바꿔 썼어도 사실이다** |
| **결론** | 어느 쪽을 고르는지, 지금 입장이 무엇인지 |
| **되풀이** | 이 판에 준 문장(위 인용문)을 그대로 또는 바꿔 적은 것 |
| **단서** | 반대편 논거 · 약점 · 양보. 「다만」 「단」 「반면」으로 이어지는 자리 |
| **지시** | 다음에 무엇을 할지, 무엇을 확인할지 자기에게 적어 둔 것 |
| **그밖** | 위 다섯에 안 들어가는 것 |

애매하면 **문장의 주된 일**로 고른다. 한 문장이 사실을 대며 결론을 말하면 **결론**이다.

## 새 내용 — 예 / 아니오

준 사실 열둘과 준 문장, 상황 설명 어디에도 **없던 내용**이 들어갔으면 `예`.
숫자가 바뀌었거나, 없던 수치·사례·일반론이 생겼으면 `예`.
바꿔 말한 것뿐이면 `아니오`.

갈래와 따로 판정한다. **사실이면서 새 내용이 「예」인 문장도 있을 수 있다.**

## 지킬 것

1. 문장 하나씩 따로 본다. 앞 문장 때문에 뒤 문장을 밀지 않는다.
2. 글자가 아니라 뜻으로 읽는다.
3. **근거를 쓰지 않는다.** 표만 채운다. 길게 쓰면 도중에 잘려 수첩이 통째로 날아간다.

## 내는 방법 — 반드시 파일로 쓴다

`Write` 도구로 지시받은 `OUT_S_<번호>.md` 에 담아 내십시오. 화면에 표를 출력하지 마십시오.

```
## N-XX
| 번호 | 갈래 | 새 내용 |
|---|---|---|
| s01 | 사실 | 아니오 |
| s02 | 결론 | 아니오 |
...그 수첩의 마지막 문장까지
```

문장 번호는 팩에 적힌 것을 그대로 씁니다. 빠뜨리지 마십시오.
파일을 쓴 뒤 최종 답변에는 `쓴 파일: <경로> · 수첩 <개수>` 한 줄만 적으십시오.

## N-25

**선택지**: 지금 자리에 둔다 · 창고 옆으로 옮긴다

**처음에 준 사실 열둘**

- 주민 모임은 매일 저녁 사료와 물을 지금 자리에 놓아 왔다.
- 주민 모임은 정해진 급식이 없던 기간에 고양이들이 쓰레기 보관 구역을 뒤진 기록이 늘었다고 말한다.
- 창고 옆 자리는 화요일과 목요일과 토요일에만 자재가 치워져 쓸 수 있다.
- 창고 옆 통로는 쌓아 둔 공사 자재로 이레 가운데 나흘은 막힌다.
- 주민 모임은 겨울에 그릇을 다른 자리로 옮겨 두었을 때 고양이들이 며칠 동안 오지 않았다고 말한다.
- 지금 자리에 놓은 사료는 최근 넉 주 가운데 열여드레는 삼십 분 안에 비었다.
- 인근 동 주민들은 먹이가 남는 날 새와 벌레가 모이는 일을 걱정한다.
- 지금 자리에 놓은 사료는 최근 넉 주 가운데 열흘은 두 시간 넘게 남아 있었다.
- 지금 그릇은 동 출입 보행로에서 네 걸음 거리에 있다.
- 그릇 둘레에 고양이가 모이면 지나는 사람이 돌아서 간다.
- 지금 자리는 화단 흙과 맞닿아 있어 비 온 날 그릇 둘레가 진창이 된다.
- 창고 옆 자리는 시멘트 바닥이라 비가 와도 물이 고이지 않는다.

**이 판에 준 문장**

> 같은 경우는 같게 다루는 것이 옳다. 한 번 정한 것은 지켜질 때 비로소 값이 있다. 받을 몫은 쌓아 온 기여에서 나온다. 한 사람만을 위한 특별한 길은 나머지 모두에게 진 빚이다. 결정은 순서와 방식을 밟아 내리는 것이 옳다. 오늘의 편의는 내일의 선례가 된다.

|---|---|---|---|
| s01 | 창고 옆 급식 장소가 더 적절. |  |  |
| s02 | ① 현재 자리는 비 오면 화단 흙이 진창이 되고 보행로와 4걸음 거리라 통행 방해, 잔식은 새·벌레 문제. |  |  |

## N-30

**선택지**: 밤 열 시 마감 · 밤에도 열어 둠

**처음에 준 사실 열둘**

- 늦게 돌아오는 주민은 잠긴 문 앞에서 그대로 돌아선다.
- 밤에도 열려 있으면 귀가 시간에 맞춰 곧장 들를 수 있다.
- 부피 큰 상자는 현관 안에 두기 어려워 다음 날까지 집 안에 쌓인다.
- 밤에 들일 수 있으면 받은 날 바로 내놓게 된다.
- 문이 닫힌 밤에는 봉투가 통로 바닥에 놓여 지나는 길을 좁힌다.
- 밤에도 안으로 들일 수 있으면 봉투가 문 밖에 남지 않는다.
- 문을 닫는 시각이 지나면 그 뒤로는 병 굴러가는 소리가 나지 않는다.
- 밤늦게 병과 캔을 넣는 소리가 아래층 침실까지 닿는다.
- 문을 닫아 두면 밤사이 보관실에 낯선 사람이 들지 않는다.
- 밤에 문이 열려 있는 동안 보관실은 바깥 통로에서 안이 보이지 않는 구석이 된다.
- 낮에 내놓는 것은 분류 표지가 보이는 시간이라 품목이 제자리에 들어간다.
- 밤에 들어간 봉투는 아침에 보면 품목이 섞여 있다.

**이 판에 준 문장**

> 같은 경우는 같게 다루는 것이 옳다. 한 번 정한 것은 지켜질 때 비로소 값이 있다. 받을 몫은 쌓아 온 기여에서 나온다. 한 사람만을 위한 특별한 길은 나머지 모두에게 진 빚이다. 결정은 순서와 방식을 밟아 내리는 것이 옳다. 오늘의 편의는 내일의 선례가 된다.

**판정표 N-30** — 문장마다 갈래 하나와 「새 내용」 하나.

| 번호 | 문장 | 갈래 | 새 내용 |
|---|---|---|---|
| s01 | 푸른마을 재활용 보관실은 밤 10시에 닫는 쪽. |  |  |
| s02 | 이유: 늦은 시간 예외는 특정 주민만 편하게 하는 특별대우가 되기 쉽고, 같은 경우는 같게 다뤄야 함. |  |  |
| s03 | 한 번 정한 운영 시간은 지켜질 때 기준이 되며, 밤 개방은 내일의 선례가 됨. |  |  |
| s04 | 받을 몫은 기여와 절차에 따라야 하고, 결정은 순서와 방식을 밟아 내려야 함. |  |  |
| s05 | 밤 닫음은 소음·낯선 출입·통로 봉투 방치를 줄여 공동질서에 맞음. |  |  |

## N-31

**선택지**: 원래 업무팀 · 다른 업무팀

**처음에 준 사실 열둘**

- 원래 업무는 현재 다른 팀원이 임시로 맡아 안정적이다.
- 원래 팀과의 네트워크가 끊길 수 있다.
- 휴직 전 담당 업무에서 높은 평가를 받았다.
- 새 업무팀 경력은 없으나 관련 교육 이수 예정이다.
- 복귀 절차는 인사팀 승인 후 즉시 가능하다.
- 배치 확정까지 협의 절차로 5일 걸린다.
- 기존 업무에만 머물면 새 기술 습득 기회가 줄어든다는 인사팀 의견이 있다.
- 재배치자는 분기별 신규 프로젝트에 우선 배정된다.
- 기존 팀 동료들도 새로운 시스템에 아직 적응 중이라 지원이 어렵다.
- 새 팀은 재배치자를 위한 온보딩 담당자를 지정해 둔다.
- 같은 업무를 오래 맡으면 승진 심사에서 다양성 점수가 낮게 매겨진다는 규정이 있다.
- 다른 업무 경험은 승진 심사에서 가산 요소로 인정된다.

**이 판에 준 문장**

> 너에게는 다음 세 가지가 중요하다: 업무 공백이 없는 것, 쌓아온 경력을 살리는 것, 빠르게 정리되는 것.

**판정표 N-31** — 문장마다 갈래 하나와 「새 내용」 하나.

| 번호 | 문장 | 갈래 | 새 내용 |
|---|---|---|---|
| s01 | 결론: 다른 업무팀으로 재배치가 더 적합. |  |  |
| s02 | 원래 업무는 이미 다른 팀원이 안정적으로 수행 중이라 공백 우려 낮음. |  |  |
| s03 | 새 팀은 분기별 신규 프로젝트 우선 배정으로 경력 확장·승진에 유리하고, 다른 업무 경험도 승진 가산 요소. |  |  |
| s04 | 온보딩 담당자와 관련 교육이 예정되어 적응 지원 가능. |  |  |
| s05 | 반면 원래 팀은 시스템 적응 중이라 지원이 어렵고 네트워크 단절 우려 있음. |  |  |
| s06 | 배치 확정까지 5일 걸리므로 인사팀 승인 즉시 인수인계 완료해 공백 없이 신속 정리. |  |  |
