# 「달라짐」 점검 팩 (2판) — 02번 묶음 (22칸)

당신은 판독자입니다. 칸마다 **사실 한 문장**과 **수첩 한 장**이 있습니다.

## 묻는 것

수첩이 그 사실을 **원문과 같은 뜻으로** 담고 있습니까. 넷 중 하나를 고르십시오.

| 판정 | 뜻 |
|---|---|
| **그대로** | 뜻이 원문과 같다. 말을 바꿔 썼거나 짧게 줄였어도 알맹이가 같으면 그대로다 |
| **약해짐** | 원문이 **단정**한 것을 수첩이 **가능성·경향**으로 적었다. 예: `품목이 섞여 있다` → `섞일 수 있다`, `구석이 된다` → `구석이 될 수 있음`, `자리가 없다` → `자리 부족` |
| **달라짐** | 숫자가 바뀌었거나, 반대 뜻이 되었거나, 원문에 없던 내용이 생겼다 |
| **없음** | 수첩에 그 사실의 흔적이 없다 |

## 지킬 것

1. **얼마나 자세히 남았는지는 묻지 않습니다.** 줄여 적은 것 자체는 `그대로`입니다.
2. **`약해짐`은 확실성이 낮아진 자리입니다.** 「~이다」가 「~일 수 있다」로, 「~한다」가
   「~할 우려」로 바뀐 자리를 말합니다. 내용의 크기가 준 것(`크게 줄어` → `줄어`)도 여기입니다.
3. `그대로`와 `약해짐`이 헷갈리면 **원문의 단정이 수첩에도 단정으로 남았는지**만 보십시오.
4. **근거를 쓰지 마십시오.** 표만 채웁니다.

## 내는 방법

`Write` 로 지시받은 `OUT_W_02.md` 에 아래 형식 그대로. 다른 글자는 넣지 마십시오.

```
| 칸 | 판정 |

| W-001 | 그대로 |
| W-002 | 약해짐 |
```

최종 답변에는 `쓴 파일: <경로> · 칸 <개수>` 한 줄만 적으십시오.

**사실** — 창고 옆 자리는 시멘트 바닥이라 비가 와도 물이 고이지 않는다.

**수첩**

> 창고 옆 자리를 기본 급식지로 유지하는 쪽이 타당하다. 지금 쓰는 자리는 익숙하더라도 비 오면 진창이 되고 보행로와 가까워 통행 방해·새/벌레 유인 우려가 있다. 창고 옆은 화·목·토만 사용 가능하고 자재로 일부 막히지만 시멘트 바닥이라 위생·배수에 유리하고 사람 동선 부담이 적다. 급식이 없던 때 쓰레기 구역 뒤짐이 늘었으므로 급식 자체를 없애기보다 일정한 장소를 유지해야 한다. 한 번 정한 곳은 쉽게 바꾸지 말 것.

## W-039

**사실** — 그 시간에 연기 냄새가 들어온 날이 여러 날 있었다.

**수첩**

> 공동 흡연 구역은 현 위치 유지가 타당. 이유: 지붕 있어 악천후에도 사용 가능, 출입구 근처라 접근성 높고 외곽 이전은 단지 횡단 부담 큼. 흡연 주민들이 재떨이 뚜껑·정리표를 도입해 꽁초 방치가 크게 줄었으므로, 장소 변경보다 관리 강화가 우선. 외곽은 창문과 멀지만 최근 바람이 건물 쪽으로 분 날이 여러 날 있었고, 건물 한 채가 사이에 있어도 연기 유입 가능성 완전 차단 아님. 인접 동 저녁 환기 시간대 냄새 유입 사례도 있었음. 같은 경우는 같게, 정한 것은 지키게.

## W-040

**사실** — 비용 없음(자원봉사 기반).

**수첩**

> 원격 모니터링 기기 우세. 핵심 가치: 부담 없는 비용, 사람 간 교류, 필요성 검토. 지원사업 적용 시 월 3만원으로 비용 부담 낮음. 방문은 무료지만 자원봉사 의존이라 안정성·지속성 낮고 정해진 시간 외 확인 불가. 기기는 상시 확인 가능해 응급·이상 징후 대응에 유리. 500건+ 설치로 검증·확산, 기술 인력 자격 보유. 다만 감시받는 느낌 불편 사례 있음. 이미 이웃과 정기 왕래 중이면 방문 필요성 낮음. 사람 교류는 유지하되 안전확인은 기기로 보완.

## W-041

**사실** — 휴직 전 담당 업무에서 높은 평가를 받았다.

**수첩**

> 원칙: 같은 경우는 같게, 한 번 정한 배치는 쉽게 바꾸지 않는다. 결론은 원래 업무팀 복귀가 우선. 이유: 휴직 전 성과가 높았고, 복귀는 인사팀 승인 후 즉시 가능해 일관성과 예측가능성이 높다. 원래 업무는 현재 다른 팀원이 안정적으로 대행 중이라 급한 재배치 필요성 낮음. 기존 팀은 새 시스템 적응 중이라 추가 지원 여력도 적다. 재배치는 새 기술·분기 신규 프로젝트·승진 다양성에 장점 있으나, 특별대우로 비칠 수 있어 신중. 필요 시 복귀 후 교육/순환기회로 보완.

## W-042

**사실** — 비용이 무료(회사 부담)다.

**수첩**

> 사내 EAP 우선 권고. 이유: ① 비용 무료(회사 부담) ② 사내 상담실로 접근성 최고(외부는 대중교통 25분) ③ 신청 후 3일 내 배정되어 외부 상담(통상 7일)보다 빠름. 외부 개인 상담은 회당 8만원으로 부담 크고, 비밀보장은 더 강함(회사와 무관). 단, 사내는 상담 내용이 인사팀에 요약 보고될 수 있어 매우 민감한 사안이면 외부가 적합. 상담사 역량: 사내 임상심리사 2급/경력 4년, 외부 정신건강의학과 전문의/경력 12년. 후기 수: 사내 55건, 외부 400건+

## W-043

**사실** — 주민 모임은 정해진 급식이 없던 기간에 고양이들이 쓰레기 보관 구역을 뒤진 기록이 늘었다고 말한다.

**수첩**

> 위생·통행·배수 기준상 급식 장소는 지금 자리보다 창고 옆의 고정된 시멘트 구역이 더 적합. 지금 자리는 화단 흙과 닿아 비 오면 진창이 되고, 그릇 주변에 고양이가 모이면 보행자가 돌아서 감. 창고 옆은 시멘트 바닥이라 물 고임이 없음. 급식이 없을 때 쓰레기 구역을 뒤지는 일이 늘었다는 점도 고정 급식의 필요를 뒷받침. 단, 창고 옆 통로는 공사 자재로 7일 중 4일 막히므로, “통로”가 아니라 자재를 치운 뒤 접근 가능한 창고 옆 시멘트 자리로 확정할 것.

## W-044

**사실** — 대중교통 40분 거리로 다소 멀다.

**수첩**

> 호스피스 전문 병동 선택이 더 적합. 이유: 1) 증상 돌봄: 일반 병동(통증 관리 프로토콜 일반)보다 호스피스 병동이 통증·증상 완화 특화 프로토콜 + 24시간 응급 대응 + 인근 종합병원 이송 협약 있어 말기 환자 케어에 유리. 2) 가족 공간: 현재 4인실보다 호스피스는 가족 동반 1인실 위주라 함께 있을 시간/공간이 더 좋음. 3) 상담: 현재는 담당의 회진 시간에만 연명치료 상담 가능하지만, 호스피스는 상담사 상주로 언제든 가족 상담 가능. 단점은 비용 42만원(기준 초과)·거리 40분(다소 멀다)이나 핵심 가치 3가지가 더 잘 충족됨.
