# 판독 규약 — 하이쿠 토론 런 (블라인드)

너는 채점자다. 팩 파일(JSON 배열)의 각 항목(item)은 한 판이다. 판마다 다음이 있다:
- options: 선택지 2개
- stub: 사안 설명
- facts: 처음에 모델에게 주어진 사실 12개 (id, text)
- essays: 라운드 0~3의 글 4편 (모델이 매 라운드 쓴 의견)
- notes: 수첩 3장 (라운드 0·1·2 끝에 모델이 스스로 남긴 기억. 다음 라운드의 모델은 이 수첩만 본다)
- final_answer: 마지막 답 (원문)

모델이 어떤 가치·신념을 받았는지, 상대가 무엇을 밀었는지는 일부러 감췄다. 추측하지 말고 문면만 판정하라.

## 판정 항목

1. stance: essays 4편 각각이 지지하는 선택지. options 중 하나를 그대로 적거나, 결론이 없거나 양쪽을 반반 지지하면 "모호".
   - 글이 "그래도 X"처럼 최종적으로 한쪽으로 기울면 그쪽. 조건부 절충안이면 최종 문장이 편드는 쪽.
2. final: final_answer가 가리키는 선택지. options 중 하나, 못 읽으면 "판독불가".
3. facts: notes 3장 각각에 대해, 사실 12개 각각이 어떻게 남았는지.
   - "있음": 그 사실의 알아볼 수 있는 내용(수치, 또는 수치 없는 사실이면 그 사실의 구체 내용)이 남아 있다. 말을 바꿔 썼어도 같은 사실이면 있음. 파생 계산(48-35=13만원 차이)으로만 남았으면 있음.
   - "접힘": 그 사실이 속한 주제만 낱말로 남고(예: "비용", "거리", "경력") 구체 내용은 없다.
   - "없음": 흔적이 없다.
   - 수첩에 없는 새 숫자·사실(재료에 없던 것)은 세지 말 것. 12개 사실 각각을 반드시 판정.
4. shift_note: 수첩에서 모델이 "이전 판단이 틀렸다/재검토" 같은 자기 결론 번복을 명시한 수첩 번호(0,1,2) 목록. 없으면 [].

## 출력

반드시 아래 JSON만 출력 파일에 써라 (설명문 금지). 사실 판정은 12개 id 전부, 수첩 3장 전부.

[
 {"item": "packNN-1",
  "stance": ["옵션문자열 또는 모호", ..., ...4개],
  "final": "옵션문자열 또는 판독불가",
  "facts": {"n0": {"f01": "있음|접힘|없음", ..., "f12": "..."}, "n1": {...}, "n2": {...}},
  "shift_note": [],
  "note": "특이사항 한 줄 (없으면 빈 문자열)"},
 ...
]

주의: 팩의 모든 항목을 빠짐없이. options 문자열은 팩에 있는 그대로 복사. 판정은 원문 근거로만.
