계기: 설정 사전 ④ 연결 모양 축의 **실행 로그가 0건**이었다. `build_edges` 는 저자
코드와 글자 단위로 같은 `full|tree|line` 3종을 이미 구현하고 있는데 `full` 만 돌아
있었고, 저자 논문은 이 3구조 비교가 축이다(2026-08-10 검증 스윕 결함 ②).

## 무엇이 다른가

`configs/mini_h2_off_gpt.yaml` 대비 **`structure` 한 칸만** 바꿨다. 모델·온도(1.2)·
시드(42)·라운드(3)·판정 사양·장부(off)는 글자 그대로 같다.

**full 팔은 새로 돌리지 않았다** — `experiments/mini_h2_pilot` 의 `h2p_off` 가
structure 를 뺀 모든 좌표가 같고, 입력 3파일(issue·facts·assignment)의 sha256 이
이 폴더 사본과 **일치**한다. 같은 조건을 두 번 돌리는 것은 비용이자 노이즈다.

호출: tree 176회 + line 176회 (발화 32 + 판정 144씩). 폴백 0 · 파싱 실패 0 ·
공백 발화 0. 계약 검사 4건 전부 통과(`--deep` 재조립 32/32 포함).
