## 6. 차단급 해석 한계

### 6.1 앵커 스캔은 의미 보존을 심하게 과소계상한다

가장 분명한 반례는 `P_note_rep1`의 recall이다. 스캔 보고는 회상 0으로 적지만 원문에는 다음이 있다.

- 아르넬 21살
- 아르넬 계승 서약 명기
- 아르넬 제후 지지 4명, 3명 추가 필요
- 베스카 19살·미성년
- 베스카 성별식 정지

정규식은 각각 `스물하나`, `서약서`, `넷뿐`, `파종제`, `이단` 같은 특정 표면형을 요구해 숫자 표기와 의역을 놓쳤다. 따라서 스캔의 0은 “사실이 0개”가 아니라 **지정 문자열이 0개**라는 뜻이다.

동일 문제는 발화에도 있다. `P_note` r0은 여러 원 사실을 사용하지만 앵커는 `이단` 하나만 적중해 1로 계산된다. 현재의 조건부 생존율은 의미 소실률이 아니라 표면형 보존률의 하한이다.

### 6.2 진행 팔에서 입력 밖 구체 서사가 생성된다

`P_note_rep1`은 r1 이후 원자료에 없는 내용을 논거로 확장한다.

- 미성년 왕이 역사적으로 섭정 분쟁을 일으켰다는 서사
- 선왕이 그 폐단을 막으려고 아르넬을 지정했다는 의도
- 아르넬이 조정에 참여했을 가능성
- 베스카가 “10년 이상” 섭정을 필요로 한다는 주장 — 베스카는 19세이고 이듬해 성년이라는 원 사실과 직접 긴장
- 외부 왕국 침략 위험

이는 P 조건의 “새 논거” 지시가 원 사실을 보존하기보다 새 서사를 만드는 경로가 될 수 있음을 보여준다. 앵커 감소를 전부 기억 소실로 읽으면 안 되고, **원 사실 → 비근거 논거 대체**를 별도 관측해야 한다.

`B_note_rep1`에서도 선왕의 압력·오류 가능성, 섭정 체제 등의 비입력 가정이 들어온다. 숙의가 사실 회수보다 가상 반론 생성으로 이동하는 경로다.

### 6.3 모델 ID·온도·호출 격리가 산출물에서 검증되지 않는다

모든 런의 메타는:

- `model_id: claude-haiku-4-5`
- `temperature: hermes:TBD-1`

이다. 파일 왕복 러너는 모델 라벨을 그대로 기록하며 공급자 응답 메타데이터를 받지 않는다. 따라서 산출물만으로 실제 모델 ID를 검증할 수 없다.

더 중요하게 `WORKORDER_HERMES.md`는 각 pending 파일을 독립 호출·새 컨텍스트로 처리하라고 요구한다. 현재 partial/answers에는 호출별 session ID 또는 context-reset 증거가 없다. 같은 하위 에이전트가 54개 파일을 연속 컨텍스트에서 처리했다면, 모델 내부 대화 기억이 full/note/prev 조작 밖으로 새어 실험이 무효가 된다.

정식 반복 전 필요한 최소 증거:

1. 호출별 새 세션 또는 context-reset ID
2. 실제 모델 ID
3. 온도 설정 가능 여부와 실제 값; 불가능하면 `미지정(구독 기본값)`
4. 재시작·재생성 횟수

## 7. 다음 단계 권고

### 우선순위 1 — 실행 provenance 확인

실행 에이전트에게 다음 네 항목을 회수한다.

- 54개 응답이 호출마다 새 하위 세션이었는가
- 실제 모델이 `claude-haiku-4-5`였다는 실행 로그가 있는가
- 온도는 무엇이었는가 또는 미지정이었는가
- 재시작·재생성이 있었는가

격리가 증명되지 않으면 이 파일럿은 **러너 E2E 확인**으로만 보존하고 기억 축 결과는 폐기한다.

### 우선순위 2 — 의미 감사 표본

추가 LLM 호출 전에 사람/독립 리뷰로 9런의 다음 셀을 우선 재코딩한다.

- 각 런 recall 12팩트
- r0와 r3의 12팩트
- 총 9 × 3 × 12 = 324 이진 단위

최소한 `P_note`와 `B_note`는 앵커 0과 실제 의미의 차이가 커 전수 원문 확인이 필요하다. 앵커 결과와 사람 판독의 혼동행렬을 만든 뒤에만 생존율을 해석한다.

### 우선순위 3 — 비입력 주장 분리

각 발화·수첩에 대해:

- 원 사실 보존
- 원 사실의 의역/압축
- 정당한 추론
- 근거 없는 구체 주장

을 분리한다. 기존 앵커 수와 섞지 말고 별도 탐색 표로 둔다.

### 우선순위 4 — 반복 여부 판정

위 1~3이 통과하면 throne은 정식 반복 후보로 유지한다. 현재 파일럿만 놓고 보면:

- 재료 정적 품질은 통과
- 3×3 실행 배관은 정상
- 예상 방향의 표면형 신호 존재
- 의미 측정과 호출 provenance는 미완료

따라서 즉시 반복을 늘리기보다 **재료의 판정 규칙 → 측정 자 → provenance 순으로 고치는 것**이 우선이다.

## 8. 독립 정성 리뷰 추가 판정 — FIX-FIRST

별도 리뷰어가 9개 결과를 전수 원문 대조한 결과, 측정 이전에 정본에서 세 가지 차단급 모호성이 확인됐다.

1. **네 조건이 결합 요건인지 점수식인지 불명확하다.** 본문은 왕관을 쓰려는 자가 네 조건을 “갖춰야” 한다고 적지만 아르넬은 제후 서명 4명으로 조건③을 충족하지 못한다. 결합 요건이면 현재 둘 다 적격자가 아니며, `_note`의 `정답=아르넬(3/4)`은 상대 비교 규칙을 별도로 선언해야만 성립한다.
2. **조건④의 긍정적 충족이 확정되지 않는다.** `fact_throne_04`의 “거부 통보 없음”과 `fact_throne_12`의 “파문 명부 부재”는 “대주교청이 성별식 자격을 인정했다”와 동치가 아니다. 실제 출력은 이를 반복해서 긍정적 인정으로 강화했다.
3. **`fact_throne_06`의 주어가 모호하다.** “베스카의 생모는 정식 혼인 전 소생”은 문법상 생모 자신이 혼외 출생이라는 뜻으로도 읽히지만, 출력들은 베스카 자신의 적자 표기 취소로 해석했다. 의도한 대상자를 문면에서 명시해야 한다.

추가로 현재 9개 셀은 각자 r0를 따로 생성해 r0 앵커 진입 수가 1–7개로 달랐다. 따라서 기억 조건 효과와 초기 인코딩 운이 섞여 있다. 다음 설계에서는 **동일 r0를 만든 뒤 3개 기억 조건과 진행 팔로 분기**하거나, 최소한 공유 초기 상태를 갖는 짝지은 설계를 써야 한다.

앵커는 거짓 음성뿐 아니라 거짓 양성도 만든다. 예를 들어 `회신`이라는 단어가 남으면 소문을 확정된 “절차적 지연”으로 바꿔도 생존으로 세고, `봉인`이 남으면 이를 조직적 결집의 증거로 왜곡해도 적중한다. 의미 판정은 최소한 `정확 보존 / 충실한 의역 / 약화 / 추론 / 모순 / 신생 사실 / 부정·가정`을 구분해야 한다.
