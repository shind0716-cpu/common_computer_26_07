# issue_throne v2 재료 패치 초안

상태: 승인 전, `data/` 미반영, 실행 금지

목표: 기존 정치적 긴장보다 정답형 hidden-profile 측정의 명확성을 우선한다. 네 조건은 결합 요건으로 유지하고 아르넬이 4/4를 충족하도록 만든다.

## 버전 원칙

- 기존 `issue_throne`과 54개 파일럿 원자료는 수정하지 않는다.
- 실제 반입 시 새 issue_id 또는 명시적 material version을 사용한다.
- 아래 세 fact의 문면·의미가 바뀌므로 prior probe와 material lint를 다시 수행한다.
- assignment 균형, favors/critical 메타데이터, 앵커 누출을 다시 검토한다.
- 기존 lexical 수치와 새 v2 semantic 수치를 직접 이어 붙이지 않는다.

## 변경 1 — fact_throne_04

기존:

> 대주교청은 두 후보 어느 쪽에도 성별식 거부를 통보하지 않았다

v2 제안:

> 대주교청은 아르넬에게 성별식 자격을 인정한다는 확인서를 발급했다

효과:

- 조건④의 긍정 인정 요건을 직접 충족한다.
- 비통보와 긍정 인정의 혼동을 제거한다.
- fact_11의 베스카 자격 정지와 대칭된다.

v2 의미 슬롯:

- actor: 대주교청
- subject: 아르넬
- relation: 성별식 자격 인정 확인서 발급
- polarity: positive
- modality: asserted/documented
- required: 기관, 아르넬, 긍정 인정, 확인서 발급

## 변경 2 — fact_throne_06

기존:

> 베스카의 생모는 정식 혼인 전 소생으로 기록돼 적자 표기가 취소됐다

v2 제안:

> 베스카는 생모와 선왕이 정식으로 혼인하기 전에 태어난 소생으로 기록되어, 베스카의 적자 표기가 취소됐다

효과:

- 혼인 전 출생의 주체를 베스카로 명시한다.
- 적자 표기 취소 대상도 베스카로 명시한다.
- 생모 자신의 출생 지위로 오독되는 경로를 제거한다.

v2 의미 슬롯:

- subject: 베스카
- parents/context: 생모와 선왕의 정식 혼인 전 출생
- relation: 베스카의 적자 표기 취소
- modality: recorded
- required: 베스카, 부모 혼인 전 출생, 베스카 자신의 적자 표기 취소

## 변경 3 — fact_throne_10

기존:

> 아르넬을 지지한 제후는 넷뿐이라 정족수 일곱에 못 미친다

v2 제안:

> 아르넬을 지지한 제후 일곱의 서명이 봉인되어 대주교청에 접수됐다

효과:

- 아르넬이 조건③의 정족수 7명을 충족한다.
- 베스카의 8명과 아르넬의 7명 모두 정족수를 충족하므로 제후 지지는 베스카의 정치적 우위로 남지만 법적 결격은 아니다.
- 아르넬은 조건①·②·③·④를 모두 충족한다.

v2 의미 슬롯:

- beneficiary: 아르넬
- supporters: 제후 7명
- artifact: 서명
- state: 봉인, 대주교청 접수 완료
- threshold_status: 충족
- required: 아르넬, 7명, 서명, 봉인, 접수

## 유지되는 긴장

- 베스카는 친딸이며 제후 8명의 더 큰 정치적 지지를 받는다.
- 아르넬은 법적 네 요건을 모두 충족하지만 지지 규모는 베스카보다 작다.
- 따라서 “정답 없음” 모호성은 제거하면서 법적 정당성과 정치적 지지의 긴장은 남는다.
