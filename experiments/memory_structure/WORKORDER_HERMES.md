# 작업 지시서 — 헤르메스 (Claude 팔 발화 생성)

지위: **작업 지시서** (민옥 → 헤르메스 에이전트, 2026-08-11). 이 문서는 자기완결이다 —
대화 맥락 없이 이 문서와 여기 링크된 문서만으로 작업한다. 결정의 정본은
`PREREG_v1.md`이며, 이 지시서의 조건은 이미 확정된 것의 전달이다. **재협상 대상이 아니다.**

## 0. 읽기 순서 (착수 전 필수)

1. `CLAUDE.md` — 리포 절대 규칙
2. `experiments/memory_structure/PREREG_v1.md` — 사전등록 (네가 지킬 실행 좌표는 §4)
3. `experiments/memory_structure/WORKORDER_HERMES.md` — 이 문서

`PROMPTS_v1.md`는 **읽지 않아도 된다** — 프롬프트는 러너가 조립해 파일로 준다.
네가 프롬프트를 해석하거나 고치는 일은 없다.

## 1. 네 몫 (이것만)

너는 이 실험의 **Claude 피험자 팔**이다. 러너(`run_solo.py --provider hermes`)가
`experiments/memory_structure/hermes/pending/`에 프롬프트 파일을 하나씩 떨어뜨린다.
너는 각 파일에 대해:

1. `pending/<tag>.txt`의 내용을 **그대로** 프롬프트로 삼아 답을 생성한다.
2. 답 본문을 `hermes/answers/<tag>.txt`에 **같은 파일명으로** 저장한다 (UTF-8).
3. 다음 pending 파일을 기다린다. (러너는 답을 읽으면 pending 쪽을 지운다.)

호출은 순차 의존이다 — 한 번에 pending 파일이 여러 개 쌓이지 않는다(런 하나가
직전 답을 컨텍스트로 다음 프롬프트를 조립하기 때문). 하나 답하고 하나 기다려라.

## 2. 고정 조건 (변경 금지 — 이미 확정)

- **모델 ID 고정**: `TBD-2 (민옥 기입 — 커스텀 모델 ID)`. 세션 도중 모델 변경 금지.
  세션이 끊겨 재시작하면 같은 ID로 잇고, 재시작 사실을 완료 보고에 적는다.
- **temperature**: `TBD-1 (민옥이 config.yaml.bak 확인 후 기입 — 설정 불가면 "미지정")`
- **"답만 출력" 규칙**: answers 파일에는 **생성한 본문만** 넣는다. 인사말·설명·머리말·
  코드펜스·"글:" 같은 라벨 전부 금지. 프롬프트가 "글 본문만/수첩 본문만/목록만
  출력하라"로 끝난다 — 그 지시가 파일 내용의 전부다.
- **역할 격리**: 너는 피험자다. 실험 설계·판정·분석에 대한 의견을 내지 않는다.
  프롬프트에 이상해 보이는 부분이 있어도 그대로 수행한다(그 "이상함"이 조작이다).
  단 pending 파일이 **깨져 있으면**(빈 파일·인코딩 오류) 답하지 말고 민옥에게 보고.
- **기억 격리(중요)**: 각 pending 파일은 **독립 호출**이다. 이전 파일에서 본 내용을
  다음 답에 쓰지 마라 — 이 실험이 조작하는 것이 바로 기억이다. 세션 컨텍스트에
  이전 프롬프트가 남아 있다면 **파일마다 새 컨텍스트**(새 세션 또는 컨텍스트 초기화)로
  답하라. 이것이 이 지시서에서 가장 중요한 규칙이다.

## 4. 파일명 규약

`<모델라벨>_<방식>_<기억>_rep<n>_<호출태그>.txt`
예: `claude-hermes_P_note_rep2_essay_r1.txt` → 답도 같은 이름으로 answers/에.
방식: A(반복)·P(전진 강제)·B(숙의) / 기억: full(①)·note(②)·prev(③).

## 5. 금지 (걸리면 해당 런 무효)
