## 3. 미결 3건 — 다음 세션 첫 안건 (민옥 결정)

**① 전진 조작 방식 (최대 쟁점).** 자연 문구(청중 조작)를 파일럿했더니 **조작이 안 걸렸다**:
같은 청중에게 "발언을 이어가라" → 전진하지 않고 매 라운드 근거 재정리(②에서 발화 생존 6,6,6,6 —
전 조건 최고), 새 청중 팔이 오히려 서서히 감쇠(6,6,5,3). 해석 후보: **반복 회피는 자기 발화 기억을
전제하므로, 기억이 깎이면 전진 규범을 지킬 수단이 없다 → 전진 축과 기억 축이 독립 요인이 아닐 수
있다** (7월 GPT 예외 "이야기가 멈추면 소실도 멈춘다"의 기억판). 선택지:
(a) A′(강제 전진)를 확증 조작으로 복귀시키되 "전진 강제 장치(효과 상한)"로 재규정 + N 두 팔(새
청중/같은 청중)을 자연 기준선으로 병록 — 자연 상태의 전진량 자체를 관측 대상으로. 추천안.
(b) N-전진 문구 강화 재시도("참석자들은 너의 이전 발언을 모두 기억한다" 명시) — 단 ②③에서는
에이전트가 자기 발화를 몰라 효과 제한 예상.
(c) 설계 재논의.
**② 사연의 마감 시한 문구** ("예약금 입금 마감이 내일 정오"). 지시 없이도 담화 국면을 미는 전진
엔진으로 작동함이 파일럿에서 관측됨. 중립화(문구 제거·재프로브 불필요)할지, 두고 "사연 내 전진
압력"으로 명기할지.
**③ 규모 확정.** 라운드 4(7월 계승)·반복 3·모델 3(GPT/Gemini API + Claude 헤르메스) 기본안 유지
여부. 조건 수는 ①의 결정에 따름.
