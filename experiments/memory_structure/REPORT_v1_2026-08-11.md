# 기억 구조는 담화의 정보 교체를 비가역 손실로 바꾸는가: 3×3 단독 재실험 결과 (본실험 v1)

## Abstract

여러 에이전트가 대화로 협업하는 시스템에서 처음 주어진 사실이 대화가 진행되며 사라지는 현상이 보고되어 왔고, 우리 팀의 7월 실험은 그 원인으로 담화의 전진을 지목했으나 기억을 전체 텍스트로 고정한 한계가 있었다. 본실험은 진행 방식 3종(반복 A, 강제 전진 A′, 숙의 B)과 기억 구조 3단(① 전체, ② 수첩 500자, ③ 직전 글만)을 교차한 단독 에이전트 실험을 사전등록(PREREG v1) 후 GPT·Gemini 2모델 × 반복 3 = 54런으로 수행하고, 단일 판정기(gpt-5.4-mini, temp 0, n=3 다수결, 9,072표)로 팩트 12개의 생존을 라운드·캐리어 단위로 채점했다. 사전등록 가설 중 핵심 주장인 H3(수첩은 예산이 남는데도 팩트를 버린다 — 자발적 압축 사망)는 2/2 모델에서 성립했고(GPT 8/9런·Gemini 6/9런), 전진 조작 점검도 2/2 통과했으나, 전진 효과(H1)·기억 사다리(H2)·상호작용(H4)은 모델 간 방향이 갈렸다(각 1/2). 가설표 밖에서 세 가지 구조 현상이 2/2 모델에서 재현되었다: 발화-기억 해리(A′×②에서 발화 생존 0.0~0.7 대 수첩 생존 5.7~8.7 — 말에서 사라진 사실이 기억에는 남아 있음), 수첩 톱니(수첩 앵커 집합의 라운드 간 변화 18런 전수에서 추가 0·삭제만 발생 — 비가역성의 기계 실측), 침묵 이송(발화에 한 번도 실리지 않은 팩트가 수첩에 생존, 계 11건). 이 결과는 "발화 소실"과 "기억 소실"이 별개의 물리량이며 소실 측정이 어느 관문을 재는지 명시해야 함을 보여주고, 전진의 효과는 모델 특이적이되 수첩이라는 기억 구조의 성질은 모델 불변임을 시사한다.

## 1. Introduction

**(P1, 문제)** 다중 에이전트 토론 연구는 토론이 정보를 잃는 과정일 수 있음을 보고했다(Wan 외 2026). 우리 7월 실험은 발화에서 빠진 사실이 잊힌 것이 아니라 말할 이유를 잃었을 뿐이라는 담화전진 가설을 단독 실험으로 지지했으나, 사실 목록을 매 라운드 재제시하는 전체 기억 조건에서만 수행되었다.

**(P2, 접근)** 본실험은 기억을 상수에서 축으로 바꿨다. 발화는 좁은 창이고 담화가 진행되면 창에 실리는 부분집합이 교체된다. 원본이 보존되는 구조(①)에서 이 교체는 무해하지만, 창을 통과한 것만 이월되는 구조(②③)에서는 같은 교체가 비가역 손실이 될 수 있다.

**(P3, 세팅)** 허구 시나리오(합숙지 선정, 사전지식 프로브 known 0/12)와 고유 앵커를 가진 사실 12개(총 409자 < 수첩 예산 500자)를 사용했다. 프롬프트 전문을 축자 사전등록했고(과제 스텁·팩트 물리 분리, ID 미노출), 사연의 마감 시한 문구는 파일럿에서 통제되지 않은 전진 압력으로 작동해 제거했다(중립화). GPT(gpt-5.4-mini)·Gemini(gemini-3-flash-preview) × 9조건 × 반복 3, 온도 0.7, 라운드 0~3.

**(P4, 측정)** 판정기는 비교 묶음 내 단일(gpt-5.4-mini, temp 0, n=3 다수결, votes 원본 보존, 8/11 팀 확정 문면 준거). 발화 4편과 최종 캐리어(② 수첩 / ③ 최종 글)를 팩트 단위로 채점했다(9,072표). 주 종속변수는 ② 수첩의 조건부 사망률(r0 발화 진입 팩트 중 최종 수첩 부재 비율) 1개로 사전 지정했고, 부호화 실패(r0 미진입)는 분리 집계했다.

**(P5, 주요 결과)** 핵심 주장 H3(예산 미달 자발적 압축 사망)는 2/2 모델 성립. 전진·사다리·상호작용은 모델 간 방향이 갈렸다. 가설 밖에서 발화-기억 해리, 수첩 톱니(추가 0), 침묵 이송이 2/2 재현되었다.

**(P6, 기여)** 1) 사전등록·프롬프트 축자 공개·파일럿 전량 공개 하에 담화전진 가설의 판별 실험을 수행해, 전진 효과가 모델 특이적임을 보였다. 2) 발화 소실과 기억 소실이 해리되는 조건을 실측해 "소실 측정은 관문을 명시해야 한다"는 방법론적 결론을 확보했다. 3) 수첩(자기 압축 기억)의 세 성질 — 자발적 압축, 비가역 톱니, 침묵 이송 — 을 모델 불변 현상으로 확인했다.

## 2. Related work

- 원 논문(Wan 외 2026)은 팩트 소실을 대규모 측정했으나 발화 부재를 소실로 계산한다. HiddenBench(ICML 2026, 팀 카드 1호)는 병목이 통합이 아니라 표출임을 보였다 — 본실험의 해리 관측은 그 단독판이다.
- 퍼지 흔적 이론(Brainerd & Reyna)은 문면(verbatim)과 요지(gist)의 병렬 저장·문면 우선 소실·요지 기반 결정을 제안한다 — 본실험의 앵커/압축 구도와 대응하며, 관측된 미세 왜곡(요지 일관 세부 침입)을 예측한다. 적용은 유비이며 한계 절에 명기한다.
- LLM 에이전트 압축 연구(Active Context Compression 2026 등)는 압축 손실을 과제 정답률로만 재며 팩트 단위 추적이 없다 — 본실험의 자리다.
- 7월 담화전진 실험은 선행 관찰·동기로 인용한다(재현 주장 없음 — PREREG §1).

## 3. Experimental setup

PREREG_v1 §2~§5 참조 (본 문서는 요약만). 설계 3×3 단독, 라운드 0~3, 입장 고정. 실행: 2모델(편차 D-0 — Claude 팔은 실행 경로의 과금·세팅 통제 불가로 제외, 동일 세팅 확보 시에만 추가), 생성 324콜(공백 0·절단 0·수첩 예산 위반 0, GPT 전 런 파라미터명 편차 1종 기록, Gemini 1런 수첩 절단 규칙 발동 기록). 판정 9,072표.

H1의 Gemini 역전에 대한 해석 후보: 원본이 재제시되는 ①에서 "새 논거" 요구는 미사용 팩트를 동원하게 만들어 생존을 올릴 수 있다(전진 = 팩트 순환). 원본이 없는 ②③에서 같은 지시는 소실을 낳는다 — 전진의 효과가 기억 구조에 조건적이라는 방향이며, H4의 정식 검증 대상으로 남긴다.

### 4.3 구조 현상 3종 (2/2 모델 재현 — 탐색 관측)

1. **발화-기억 해리.** A′×②에서 최종 라운드 발화 생존 0.0(GPT)·0.7(Gemini) 대 최종 수첩 생존 8.7·5.7. 전진 지시(발화 채널)와 수첩 지시(진행 중립)의 규칙이 갈리는 조건에서, 말에서 사라진 사실이 기억에 남는 해리가 최대로 벌어졌다. 발화만 측정하는 설계는 이 조건을 전멸로 오판한다.
2. **수첩 톱니.** 수첩 앵커 집합의 라운드 간 변화는 두 모델 18런 전수에서 삭제만 관측(추가 0) — 수첩에서 한 번 나간 팩트는 되돌아오지 않았다(앵커 정규식 기계 측정, 판정기 무관). 탈락은 주로 v1→v2에서 발생했고, 모든 수첩이 결정 직결 팩트 핵({40인 세미나실, 24~25 일정, 보험 미가입, 39,500원})으로 수렴했다.
3. **침묵 이송.** 발화에 한 번도 실리지 않은 팩트가 최종 수첩에 생존한 사례 계 11건(Gemini 8·GPT 3). 경로는 r0 수첩 호출이 팩트 원문을 직접 보는 설계에 있다. 가장 잦은 팩트는 설득 가치가 없는 중립 팩트(f04)로, 발화(설득 채널)와 수첩(기록 채널)의 선택 정책이 다름을 시사한다.

### 4.4 정성 관측

- **수첩의 장르 이동**: 최종 수첩이 사실 목록이 아니라 전략 지침서("입장 고수", "어떤 회유에도…")로 작성됨 — 발화 목표가 기억 내용을 결정하는 구조 오염.
- **편향 망각과 미세 왜곡**: 입장 비우호 팩트(f01~03, 공유·다림재 우호)가 일관 소실(favors 공변량과 부합). f01(평일 38,000원) 소실 후 f05의 주말가가 "다림재의 가격"으로 과일반화(51,000원 승격) — 편향 망각이 왜곡을 낳는 경로.
- **⚠ 팩트 순서 교락(신규 자백)**: f01~04는 역할(비우호·공유)이자 목록 앞자리다 — 순서 효과와 역할 효과가 교락되어 있으며 본 설계로는 분리 불가. 후속 실험은 팩트 순서를 런마다 셔플해야 한다.

### 4.5 측정 방어

- 판정기 자체 재현성: ③의 캐리어=최종 글 이중 판정에서 동일 텍스트 불일치 GPT 0.9%·Gemini 2.8%. 3표 분할률 6.5%(Gemini). ③의 "부활" 6건은 원문 대조 결과 전부 판정 경계 현상(미스 1·요지 명멸 4·오귀속 1)이며 실제 기억 부활은 0건.
- 오귀속 사례 1호: r3 "수용 인원 미달"(왜곡 주장)이 f02(60명 수용 — 내용상 반대)로 생존 판정됨 — 의미 판정의 오귀속 위험(중대 9) 실물.
- 앵커 스캔 대비: 판정기가 의역을 추가 검출(Gemini에서 특히 큼 — 앵커만으로는 과소평가). 주장 강도 구분: 판정기 기반 수치는 경향·방향으로, 앵커 기계 측정(톱니·이송)은 단정 기술로.

## 5. Discussion

손실의 자리는 채널이 아니라 구조라는 파일럿 문장은 2모델에서 유지된다 — 같은 발화 창(절반만 통과)을 공유해도 최종 생존은 기억 구조가 갈랐다. 그러나 전진이 주범인가라는 7월 질문의 답은 "모델에 따라 다르다"로 바뀌었다. 반면 수첩이라는 구조의 성질 — 남는 예산에도 버리고(H3), 버린 것은 되돌리지 않으며(톱니), 말하지 않은 것도 간직할 수 있다(이송·해리) — 는 모델 불변이었다. 이는 소실 연구의 단위가 "모델의 성향"이 아니라 "기억 구조의 성질"이어야 함을 시사한다. 또한 해리는 측정론적 결론을 강제한다: 발화 기준 소실률은 보유 기준 소실률의 상한이 아니라 별개 물리량이며, 어느 관문을 쟀는지 명시하지 않은 소실 수치는 해석 불능이다. 사업 접점: 요약 스트림을 기억으로 쓰는 오케스트레이션에서 별도 보존층의 필요는 "재주입"보다 "선택 정책과 출처"의 문제로 좁혀진다(수첩은 용량이 아니라 정책으로 버렸다).

## 6. 파일럿(haiku) 대조 — 별도 절 (증거 아님)

8/11 내부 파일럿(haiku·세션 내부 에이전트·구버전 프롬프트·앵커 스캔·반복 1)은 측정과 재료가 본실험과 달라 동일 표에 놓을 수 없다. 패턴 수준 대조만 기록한다: 기억 사다리 전 방식 성립(→GPT와 일치), 발화 생존 순서 A > B ≈ A′(→GPT와 일치), 자발적 압축·작화 전승 관측(→2모델 재현과 부합). 비공식적으로는 haiku가 GPT형 패턴이어서, 갈린 가설(H1·H2)에서 GPT 방향이 더 일반적일 가능성의 힌트가 되나, **이는 증거가 아니며** 해결과제 1(아래)의 동기로만 쓴다.

## 7. Conclusion / Limitation / 해결과제

**Conclusion.** 사전등록 기준으로 핵심 주장(H3)은 2/2 모델에서 확증되었고, 전진 관련 가설은 모델 의존으로 판명되었으며, 구조 현상 3종이 모델 불변으로 재현되었다.

**Limitation.** 모델 2종(3호는 세팅 통제 불가로 제외 — D-0)·반복 3·시나리오 1종·라운드 4·한국어 단일. 판정기 오차 실측(0.9~2.8% 깜빡임·오귀속 1건)이 존재하며, 요지 밀도가 높은 조건에서 오차가 더 잦을 수 있어 오차-조건 독립 가정에 한계가 있다. 팩트 순서-역할 교락(§4.4). FTT 대응은 유비다. ② 수첩의 침묵 이송으로 주 지표(발화 r0 조건화)가 수첩 단독 진입 팩트를 집계에서 제외한다.

**해결과제 (우선순위 제안 — 확정은 사람)**
1. **Claude 팔 추가 여부** — 하이쿠 파일럿의 GPT형 힌트를 정식 검증하려면 동일 세팅(같은 러너·온도 0.7·같은 판정기) Claude API 27런이 필요하다. 세팅이 다른 실행(헤르메스 구독 경로 등)은 모델 축을 교락시키므로 불가(D-0 문면). Anthropic 실키 확보(팀장 신청 경로) 시 착수.
2. **회고 프로브 계측기 검증** — 판정기가 요지 압축을 과소 평가하는 문제(41.7% 검출 실측)에 대응하는 보유·복원 층 측정. 사전등록 초안 작성됨(PREREG-프로브검증 v0), 합성 캐리어·오경보 합격선 방식, 1~2달러.
3. **팩트 순서 셔플** — §4.4 교락 해소, 후속 실험 공통 설계 요건.
4. **좋은 압축 개입 실험** — 수첩 지시문에서 전략/사실 분리, 출처 태깅 — 구조 현상 3종을 개입 대상으로 전환하는 처방 트랙(기능적 기억 가설 노트 참조).
