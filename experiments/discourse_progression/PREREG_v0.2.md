## 1. 가설 (v0.1과 동일 — 재기재)

**담화 전진 가설 (분해형)**: 발화 소실은 전진 성분 + 동조 성분(+판정 잡음)으로
분해되며, 전진 성분은 사회적 상호작용 없이 단독으로도 발화를 비운다.
(따름정리: 논문의 무상호작용 통제가 팩트를 보존한 것은 전진 없는 반복 조건이기 때문.)

전진의 조작적 정의: 라운드 r(≥1)의 전진 점수 = 1 − J(r, r−1),
J = 직전 라운드 발화와의 문자 2-그램 자카드 유사도. 순수 계산(LLM 0).

가능성은 낮으나 한계 절에 명기한다.

## 3. 판별 기준 (v0.1 문면 계승 — 모델별 독립 판정)

각 모델에 대해 독립적으로:

| # | 기준 | 판정 |
|---|---|---|
| P1 | A′의 런 평균 최저 생존 < A의 런 평균 최저 생존 (차이 ≥ 1팩트) | 성립 시 전진 단독 효과 |
| P2 | B 3런 중 2런 이상에서 최저점 < 최종점 (급락 후 회복) | 추상화 소실 패턴 |
| P3 | 낙폭 최대 B 전이 텍스트 재채점 3회, 각 회가 다수 라벨과 ≥10/12 일치 | 미달 시 해당 모델 P2 유보 |
| P4 | P1 불성립 시 "재진술 감쇠 지배, 전진 효과 미검출"로 보고 | 침묵 금지 |
| P5 | 모델 내 전이 풀링(n=27): 전진 점수와 신규 소실의 스피어만 ρ > 0 그리고 전진 상위 절반 평균 소실 > 하위 절반 | 관계식 확인 |

## 4. 복제 판정 R1 (신규 — 승격 규칙)

- **2/2 모델에서 P1 성립** → 완전 복제. 보고서 v1 승격, 데모 딱지 제거
  (지위: 발표용 상급, 논문 파일럿 인용 가능).
- **1/2** → 부분 복제. "전진 효과는 모델 의존적"으로 그대로 보고 — 이것도 발견이다.
- **0/2** → 미재현. 데모 결과를 "소넷 한정 관찰"로 강등하고 색인에 정정 줄 추가.

어느 경우든 결과를 보고 나서 모델을 빼거나 기준을 바꾸지 않는다.
