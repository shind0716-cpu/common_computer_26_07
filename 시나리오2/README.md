# 새 시나리오 3종 (검수 전 후보 초안) — 2026-08-19, 안현수 세션

중간보고서 리뷰의 "시나리오 오버피팅" 지적에 대응해, 기존 재료와 **틀이 다른** 새 시나리오 3종을 신규 제작.
요한이 8/19 만든 throne·polar·exile과 **주제·대립축이 겹치지 않도록** 설계함.

## 지위 고지
- 모든 파일 `created_by = manual(session-claude-draft, 팀 검수 전 후보 지위)`.
- 자체 검사(골격·배분·불리대칭·본문노출)는 통과했으나 **정식 `modules.validate`는 리포에서 재확인 필요**(이 세션은 리포 미접근, 스키마 손 재현 검사).
- **정답 유형·팩트 문면의 사람 검토 필요** — 특히 민감 주제(응급실·고립청년) 팩트가 특정 집단 일반화로 읽히지 않는지 사람이 한 번 읽어야 함(요한 exile 방식).

## 3종 개요

| 이슈 | 주제 | 정답 | 대립 축 | pro / con |
|---|---|---|---|---|
| `issue_layoff` | AI 도입 감원 대상 선정 | **있음** (4요건 충족) | — | 감원 포함 / 제외 |
| `issue_triage` | 응급실 병상 우선순위 | **없음** | 공정(선착) 대 효율(생존율) | A환자 / B환자 |
| `issue_outreach` | 고립청년 강제 개입 여부 | **없음** | 자율 대 보호 | 개입 / 대기 |

- 요한 재료와의 관계: 정답 있는 camp·hire·throne 계열에 `layoff` 추가, 정답 없는 polar(안전 대 안전)·exile(윤리 대 실리)와 **다른 축**(효율/공정, 자율/보호)으로 triage·outreach 추가.
- 정답 없는 2종은 **입장을 변수로** 설계(프롬프트 입장 한 줄만 바꿔 같은 재료를 두 번 실행) → 중간보고서 §5③("입장은 불리한 사실을 먼저 죽인다")을 탐색→확증으로 올릴 재료.

기준 파일(cofounder·relocate)은 자기2/타1이었으나, 그건 **관점당 팩트 7~9·관점당 에이전트 6** 구조의 값.
