# 실험 콘솔 — 켜는 법 (2026-09-03)

> 지위: 확정(사용 안내). 담당: 민옥. 처음 보는 사람이 이 파일만 읽고 콘솔을 켜서 압박 실험 결과를 볼 수 있게 쓴 글이다.
> 화면 안의 설명은 콘솔 첫 화면 「안내」 탭에 있다. 이 파일은 **켜기·키·오류**만 다룬다.

## 1. 무엇인가

`tools/console/`은 팀의 실험 파이프라인을 브라우저에서 돌리고 결과를 들여다보는 로컬 웹앱이다.
파일은 둘뿐이다 — `app.py`(서버, FastAPI)와 `index.html`(화면 하나에 글·모양·동작이 전부).
지금 실제로 쓰는 실험은 **압박 실험**(`experiments/pressure_category/`)이고, 콘솔은 그 러너(`run_pressure.py`)를
대신 불러 주고 결과 파일(`runs/`)을 읽어 보여 주기만 한다. 채점·집계 산식은 전부 실험 폴더의 스크립트가 정본이다.

## 2. 설치

| 필요한 것 | 확인 방법 | 비고 |
|---|---|---|
| 파이썬 3.10 이상 (팀은 3.13 사용) | `python --version` | 없으면 리포 루트의 `quickstart.bat` 참고 |
| 파이썬 패키지 5개 | `pip install -r tools/console/requirements.txt` | fastapi · uvicorn · pyyaml · python-dotenv · requests. `run_console.bat`이 켤 때마다 자동으로 설치한다 |
| (실험을 직접 돌릴 때만) API 키 | 아래 4절 | 결과 보기 탭은 키 없이 된다 |

인터넷은 패키지 설치와 실제 실행(AI 호출) 때만 필요하다. 콘솔 자체는 외부 파일을 하나도 안 불러온다(오프라인에서 켜진다).

## 3. 켜기

**가장 쉬운 방법** — 리포 루트의 `run_console.bat`을 더블클릭한다. 검은 창이 뜨고 세 단계(패키지 설치 → 키 점검 → 서버 시작)를
지난 뒤 브라우저가 `http://127.0.0.1:8021`을 연다. **그 검은 창을 닫으면 서버가 꺼진다.**

**손으로 켜기** — 리포 루트에서:

```
python -m uvicorn tools.console.app:app --port 8021
```

그다음 브라우저에서 `http://127.0.0.1:8021`. 포트 8021이 이미 쓰이고 있으면 `--port 8022`처럼 다른 번호로 켜고 주소도 그 번호로.

**끄기** — 검은 창을 닫거나 그 창에서 `Ctrl+C`.

이 콘솔은 로그인이 없다. **내 컴퓨터에서만** 켜고, 다른 사람이 접속할 수 있는 주소로 열지 않는다.

## 4. `.env`와 API 키 — 어떤 키가 어떤 탭에 필요한가

1. 리포 루트의 `.env.example`을 복사해 `.env`로 저장한다(같은 폴더). `.env`는 절대 커밋하지 않는다.
2. 쓸 모델의 키를 넣는다. 24자 미만이면 자리표시자로 보고 없는 것으로 친다.

| 콘솔에서 고르는 모델 이름 | 넣어야 하는 키 |
|---|---|
| claude-haiku · claude-sonnet | `ANTHROPIC_API_KEY` |
| gpt · gpt-mini | `OPENAI_API_KEY` (모델 번호는 `OPENAI_MODEL`) |
| gemini-flash | `GEMINI_API_KEY` (모델 번호는 `GEMINI_MODEL`) |

| 탭 | 키가 필요한 일 | 키 없이 되는 일 |
|---|---|---|
| 안내 | 없음 | 전부 |
| 압박 실행 | 실제 실행(요금 발생) · 일괄 실제 실행 | 예상 호출 수 계산, 각본·가치 세트·신념 등록(파일 쓰기만). ⚠ 키가 하나도 없으면 모델 목록이 전부 회색으로 잠겨 **연습 실행도 화면에서는 못 한다** — 명령줄 `python experiments/pressure_category/run_pressure.py --dry …`는 된다 |
| 압박 결과 · 압박 집계 · 발표 모드 | 없음 | 전부 (이미 있는 `runs/` 결과를 읽기만 한다) |
| 보관 ▸ 토론 4탭 | 토론 실행 · 채점 · 개입(각각 고른 모델의 키) | 시나리오 열람, 수첩·채점 결과 열람 |
| 보관 ▸ 단독 3탭 | 단독 실제 실행 | 단독 결과·생존 격자 열람, 연습 실행 |

키가 있는지 미리 보려면 리포 루트에서 `python -m tools.console.keycheck`. `run_console.bat`은 `.env`가 있을 때 이것을 자동으로 한 번 돌린다.

## 5. 처음이라면 이 순서로

1. 콘솔을 켜면 **안내** 탭이 먼저 열린다 — 이 콘솔이 무엇인지, 자주 쓰는 말(판·수첩·가치 세트·압박 각본 …)이 거기 있다.
2. **압박 결과** 탭에서 판 하나를 눌러 라운드별 원문을 읽는다. "한 판"이 어떤 것인지 5분이면 감이 온다.
3. **압박 집계** 탭에서 시나리오 한 줄을 눌러 상세를 본다. 어느 카테고리의 사실이 남고 사라졌는지 표로 보인다.
4. 직접 돌려 보려면 **압박 실행** 탭 — 시나리오·가치 세트·압박 각본을 고르고 **연습 실행**(AI 호출 0)으로 AI에게 보낼 글을 확인한 뒤,
   사전등록 문서(`experiments/pressure_category/PREREG_v0.md`)를 커밋했다는 확인을 켜고 **실제 실행**(요금 발생).

## 6. 흔한 오류와 대처

| 증상 | 원인 | 대처 |
|---|---|---|
| bat 창에 `파이썬을 찾지 못했습니다` | 파이썬이 없거나 PATH에 없음 | 파이썬 설치 후 다시. 리포 루트 `quickstart.bat` 참고 |
| 브라우저가 안 열리거나 `Address already in use` | 포트 8021이 이미 쓰임(이전에 켠 창이 살아 있음) | 이전 검은 창을 닫거나, `--port 8022`로 켜고 주소도 8022로 |
| 모델 목록이 비어 있거나 전부 회색 | `.env`가 없거나 키가 자리표시자 | 4절대로 `.env`에 키. 넣은 뒤 **서버를 다시 켠다** |
| 「실제 실행」 버튼이 눌리지 않음 | 예상 호출 수가 안 나왔거나, `PREREG_v0.md 를 로컬 커밋했습니까?` 확인이 꺼져 있음 | 시나리오·가치 세트·각본·반복을 하나 이상 고르고, 사전등록 문서를 커밋한 뒤 확인을 켠다. 콘솔은 이 확인을 대신 켜 주지 않는다 |
| 압박 집계 탭이 한참 "읽어 채점하는 중" | `runs/`의 판 파일 3,000개 이상을 전부 읽는다 | 몇 초에서 수십 초. 「새로고침」을 반복해서 누르지 않는다 |
| 화면 글자를 고쳤는데 안 바뀜 / `app.py`를 고쳤는데 안 바뀜 | `index.html`은 요청마다 다시 읽지만 `app.py`는 켤 때 한 번 읽는다 | `index.html` → 브라우저 새로고침. `app.py` → 검은 창을 닫고 `run_console.bat` 다시 |
| `run_console.bat` 안의 한글이 깨져 보이거나 실행이 이상함 | bat 파일을 UTF-8 편집기로 저장했음 | bat은 cp949·CRLF여야 한다. 손으로 고치지 말고 `python tools/console/_mkbat.py`로 다시 만든다 |
| 「지금 도는 것은 다른 실행입니다」 | 실행 자리는 1개 — 다른 탭의 실행이 도는 중 | 그 탭에서 끝나기를 기다리거나 「중단」 |

## 7. 탭 한 줄씩

| 탭 | 한 줄 |
|---|---|
| 안내 | 이 콘솔이 무엇인지 · 압박 실험 흐름 그림 · 자주 쓰는 말 · 처음 순서. 아무것도 실행하지 않는다 |

## 8. 개발자 메모

- **코드를 고치면**: `app.py`는 서버를 다시 켜야 반영된다. `index.html`은 새로고침이면 된다(서버가 요청마다 파일을 다시 읽는다).
- 테스트: 리포 루트에서 `python -m unittest tests.test_console tests.test_console_gates` (pytest가 없어도 된다).
  2026-09-03 기준 55개 중 1개가 실패한다(`promotion_tier` — 08-24 회귀, 상세는 `_review/REVIEW_2026-09-03.md` §1-2 ①).
- 화면 스크린샷·검토 기록: `tools/console/_review/`. 스크린샷 도구 `python tools/console/_review/shots.py --phase after` (Playwright 필요, 서버 켜 둔 채).
- 파일 규칙: 데이터 키(라벨 값·run_id·C0/C1/C2·API 경로)는 화면 말을 바꿔도 그대로다. 화면 표기는 `index.html`의 표시 사전(`PL_KO`·`SC_KO`)에서만 바꾼다.
