### 1-2. 지시서 모순·빈틈 (실행 전 발견분 — 조사 결과 반영분은 1-3)
① **0단계 기준선 테스트가 이미 실패**: `tests.test_console_gates.TestVariant.test_variant_surfaces_as_pilot_candidate_never_confirmatory` — `KeyError: 'promotion_tier'`. 원인: 08-21 요한 커밋 45cb300이 테스트를 추가했으나 민옥 소유 `app.py`에는 `promotion_tier`가 한 번도 들어간 적 없음(grep 0건, app.py 이력에 요한 커밋 없음). 표시층 작업과 무관한 기존 실패. 지시서 §8은 "멈춘다"이나 **민옥이 채팅으로 "기록만 하고 진행" 확정** → 기준선 = 2종 55개 중 54 통과·1 에러, 종료 조건 = "새 실패 0". (참고: 콘솔 테스트 4종 전체는 123개 중 failures 11·errors 8, 전부 promotion_tier/파일럿 관문/v2 registry 계열 — 같은 뿌리.)
② **`run_console.bat` 위치**: 지시서 §0·§3-5는 `tools/console/`에 있는 것처럼 적었으나 실제는 **리포 루트**에 있고, `tools/console/_mkbat.py`가 루트에 cp949·CRLF로 생성한다(`.gitattributes`에 `*.bat text eol=crlf`). 5단계는 생성기(`_mkbat.py`, 민옥 소유)를 고쳐 재생성한다.
③ **pytest 미설치**: 시스템 Python 3.13·3.12 모두 없음. 지시서는 `python -m pytest …`를 명하나 §2가 새 의존성을 금하고 playwright만 허용. 테스트 파일은 전부 `unittest.TestCase`라 `python -m unittest`로 같은 테스트가 돈다 → 대체. (WORKLOG에도 "pytest 부재로 unittest discover" 전례 있음.)
④ **"11탭"** 셈법: nav 버튼은 10개(scn·setup·notes·iv·srun·sres·sgrid·prun·pres·pcat) + 발표 모드는 탭이 아니라 새 창 링크. 스크린샷은 10탭 + `present.png`(자족 페이지 4.8MB라 첫 화면만) + `_landing.png`(첫 화면) = 12장.
⑤ **worktree에 `.env` 없음**(gitignore) — 의도와 일치(LLM 호출 0). 콘솔은 키 없이 뜨고 모델 목록이 비어 보인다. 스크린샷은 그 상태로 찍힌다(민옥 환경에서는 모델 목록이 채워져 보임).
⑥ **콘솔 에러 기준선의 정의**: 지시서가 안 정함 → "페이지 로드+10탭 순회 동안 console.error + pageerror 수"로 정의. 기준선 2건 — 둘 다 로드 직후 빈 선택으로 `/api/solo/estimate`·`/api/pressure/estimate`가 400을 돌려주며 나는 "Failed to load resource". 기능 그대로이므로 후에도 2건이어야 정상.
⑦ **CLAUDE.md 규칙 3(`python -m modules.validate`)**: 이 작업 산출물(HTML·md·png)은 validate 대상 스키마가 아님 → 적용 불가로 기록. 규칙 2(경로 하드코딩 금지)는 shots.py가 `Path(__file__)` 상대 경로만 씀.
